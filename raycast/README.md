# Fmind for Raycast

A light theme for [Raycast](https://raycast.com).

## Installation

1. In Raycast, open Settings (`Cmd+,`).
2. Go to **Appearance** → **Themes**.
3. Import or configure a custom light theme with the parameters in [fmind.json](fmind.json):
   - **Background**: `#ffffff`
   - **Secondary Background**: `#f1f3f4`
   - **Text**: `#202124`
   - **Selection**: `#d2e3fc`
   - **Loader**: `#174ea6`
