# Mousepad

Fmind light color scheme for Mousepad (Xfce text editor).

## Installation

1. Copy `fmind.xml` to `~/.local/share/gtksourceview-4/styles/` (or `gtksourceview-3.0/styles/` depending on your GtkSourceView version).
2. In Mousepad, go to **Preferences → View → Color Scheme** and select **Fmind**.
