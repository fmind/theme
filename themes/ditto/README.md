# Ditto

Fmind theme for [Ditto](https://ditto-cp.sourceforge.io/).

Format: [Ditto Theme.cpp](https://github.com/sabrogden/Ditto/blob/master/src/Theme.cpp) · [bundled themes](https://github.com/sabrogden/Ditto/tree/master/Debug/Themes)

## Install

Copy `Fmind.xml` to `Themes/` within your Ditto installation directory.
