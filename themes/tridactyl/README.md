# Fmind for Tridactyl

Light theme for Firefox [Tridactyl](https://github.com/tridactyl/tridactyl) extension.

Format: [Tridactyl default.css](https://github.com/tridactyl/tridactyl/blob/master/src/static/themes/default/default.css) · [Tridactyl :colourscheme](https://github.com/tridactyl/tridactyl/blob/master/src/excmds.ts)

## Installation

Copy [fmind.css](fmind.css) to `~/.config/tridactyl/themes/fmind.css` and run `:colors fmind` in Tridactyl. Loading themes from that folder needs Tridactyl's [native messenger](https://github.com/tridactyl/tridactyl#extra-features-through-native-messaging) (`:installnative`).
