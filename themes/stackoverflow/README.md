# Stack Overflow

Fmind user style for [Stack Overflow](https://stackoverflow.com/).

Format: [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS) · [Stacks](https://github.com/StackExchange/Stacks)

## Install

Install using the [Stylus](https://add0n.com/stylus.html) extension and apply `fmind.user.css`.
