# Fmind for Wofi

Files: [fmind.css](fmind.css).

## Installation

Merge fragments into existing settings.

Copy to `~/.config/wofi/style.css`, or pass `--style /path/to/fmind.css` to Wofi. Includes input, rows, selection, hover and scrollbar styles. Disable `allow_markup` when displaying externally colored Pango markup to preserve these text colors.
