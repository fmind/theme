# KiCad

Fmind light color theme for KiCad schematics.

Format: [KiCad color_settings.cpp](https://gitlab.com/kicad/code/kicad/-/blob/master/common/settings/color_settings.cpp)

## Install

Copy `fmind.json` to `~/.config/kicad/8.0/colors/` (or your KiCad version directory) and select Fmind in Preferences → Schematic Editor → Colors.
