# ncspot

Fmind theme for [ncspot](https://github.com/hrkfdn/ncspot).

Format: [ncspot theming](https://github.com/hrkfdn/ncspot/blob/main/doc/users.md#theming) · [theme loader](https://github.com/hrkfdn/ncspot/blob/main/src/theme.rs)

## Install

Merge `[theme]` configuration from `config.toml` into `~/.config/ncspot/config.toml`.
