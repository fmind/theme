# Fmind for Terminal.app

Files: [fmind.terminal](fmind.terminal).

Format: [Apple Terminal profiles](https://support.apple.com/guide/terminal/import-and-export-terminal-profiles-trml4299c696/mac)

## Installation

On macOS, Settings → Profiles → action menu → Import; select the file and choose Fmind. Set the profile as Default for new windows if desired. Font choice remains in the profile settings.
