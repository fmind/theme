# PL/SQL Developer

Fmind color scheme for [PL/SQL Developer](https://www.allroundautomations.com/products/pl-sql-developer/).

Format: [Allround Automations light.ini](https://www.allroundautomations.com/download/light.zip) · [Themes folder](https://forums.allroundautomations.com/threads/incorrect-default-editor-colors-in-light-mode-in-beta-3-and-earlier.16569)

## Install

PL/SQL Developer 15 or later reads its light-mode colors from `light.ini` in its `Themes` folder.

1. Exit PL/SQL Developer.
2. Back up `%APPDATA%\PLSQL Developer <version>\Preferences\Themes\light.ini`, such as `%APPDATA%\PLSQL Developer 15\Preferences\Themes\light.ini`.
3. Save [Fmind.ini](Fmind.ini) in its place as `light.ini`.
4. Restart PL/SQL Developer. The colors apply in light mode.
