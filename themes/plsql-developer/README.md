# PL/SQL Developer

Fmind color scheme for [PL/SQL Developer](https://www.allroundautomations.com/products/pl-sql-developer/).

## Install

1. Copy `Fmind.ini` to your PL/SQL Developer preferences folder.
2. In PL/SQL Developer, go to `Configure` -> `Preferences` -> `User Interface` -> `Colors`.
3. Load the `Fmind` scheme.
