# Fmind for PolyMC

Light color theme for [PolyMC](https://polymc.org/).

Format: [PolyMC custom theme loader](https://github.com/PolyMC/PolyMC/blob/develop/launcher/ui/themes/CustomTheme.cpp)

## Installation

PolyMC loads one custom theme, from `themes/custom/theme.json` in its data folder. Copy [theme.json](theme.json) there: `~/.local/share/PolyMC/themes/custom/theme.json` on Linux (`~/.local/share/polymc/` for older installs), `%APPDATA%\PolyMC\themes\custom\theme.json` on Windows or `~/Library/Application Support/PolyMC/themes/custom/theme.json` on macOS. A portable install uses the folder that holds `portable.txt`. Restart PolyMC, then select **Fmind** as the launcher theme in its settings.
