# Fmind for Sublime Text

Files: [fmind.sublime-color-scheme](fmind.sublime-color-scheme).

Format: [Sublime Text color schemes](https://www.sublimetext.com/docs/color_schemes.html)

## Installation

Use Preferences → Browse Packages; copy into `User/`, then choose `fmind` with Select Color Scheme. This styles editor content; the UI theme is separate.
