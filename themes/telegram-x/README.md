# Fmind for Telegram X

Light theme for [Telegram X](https://t.me/tgandroidexperimental) Android client.

Format: [theme parser](https://github.com/TGX-Android/Telegram-X/blob/main/app/src/main/java/org/thunderdog/challegram/telegram/TdlibUi.java) · [bundled themes](https://github.com/TGX-Android/Telegram-X/tree/main/app/src/main/other/themes)

## Installation

Send [fmind.tgx-theme](fmind.tgx-theme) to any chat in Telegram X, such as Saved Messages, tap the file and choose **Apply theme**. The theme builds on the built-in Blue theme and recolors text, surfaces and accents.
