# Fmind for Swaylock

Files: [fmind.conf](fmind.conf).

Format: [swaylock(1)](https://github.com/swaywm/swaylock/blob/master/swaylock.1.scd)

## Installation

Merge into `~/.config/swaylock/config`, or use `swaylock --config /path/to/fmind.conf` to select this color configuration. Supports core swaylock; styles idle, clear, Caps Lock, verification and error states.
