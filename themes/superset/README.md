# Fmind for Apache Superset

Light color scheme for [Apache Superset](https://superset.apache.org/).

## Installation

Requires Superset 6.0 or later. In **Settings → Themes**, click **+ Theme**, paste [fmind.json](fmind.json) as the theme definition, and save; or merge its tokens into `THEME_DEFAULT["token"]` in `superset_config.py`.
