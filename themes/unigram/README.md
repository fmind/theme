# Unigram

Fmind theme for [Unigram](https://github.com/UnigramDev/Unigram).

Format: [Unigram ThemeCustomInfo.cs](https://github.com/UnigramDev/Unigram/blob/develop/Telegram/Services/Theme/ThemeCustomInfo.cs) · [Unigram theme keys](https://github.com/UnigramDev/Unigram/blob/develop/Telegram/Services/ThemeService.Defaults.cs)

## Install

Open `Fmind.unigram-theme` in Unigram to apply the theme.
