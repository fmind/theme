# Fmind for Unraid

Light dashboard stylesheet for [Unraid](https://unraid.net/).

Format: [Unraid white.css](https://github.com/unraid/webgui/blob/master/emhttp/plugins/dynamix/styles/themes/white.css) · [Dynamix theme system](https://github.com/unraid/webgui/blob/master/emhttp/plugins/dynamix/styles/themes/README.md)

## Installation

Select the **white** theme under Settings → Display Settings, because [fmind.css](fmind.css) overrides that theme's variables (Unraid 7.1 or later). On Unraid 7.2 or later, install the [Custom WebUI CSS](https://github.com/WuSiYu/unraid-custom-css) plugin, open Settings → Utilities → Custom WebUI CSS, paste the file and click **Apply & Save**. On Unraid 7.1, paste it into the custom CSS of the [Theme Engine](https://forums.unraid.net/topic/87126-plugin-theme-engine-a-webgui-styler/) plugin instead.
