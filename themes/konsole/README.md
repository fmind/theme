# Fmind for Konsole

Files: [fmind.colorscheme](fmind.colorscheme).

Format: [Konsole ColorScheme.cpp](https://invent.kde.org/utilities/konsole/-/blob/master/src/colorscheme/ColorScheme.cpp)

## Installation

Copy to `~/.local/share/konsole/fmind.colorscheme`; select `fmind` under Edit Profile → Appearance. Selection and cursor use Konsole’s profile behavior.
