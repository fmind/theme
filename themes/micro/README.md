# Fmind for Micro

Files: [fmind.micro](fmind.micro).

Format: [micro colors.md](https://github.com/micro-editor/micro/blob/master/runtime/help/colors.md)

## Installation

Copy to `~/.config/micro/colorschemes/fmind.micro`; run `set colorscheme fmind` in the Ctrl-E command prompt. Requires truecolor.
