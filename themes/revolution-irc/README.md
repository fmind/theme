# Fmind for Revolution IRC

Light theme for [Revolution IRC](https://github.com/MCMrARM/revolution-irc).

Format: [ThemeInfo.java](https://github.com/MCMrARM/revolution-irc/blob/master/app/src/main/java/io/mrarm/irc/util/theme/ThemeInfo.java) · [ThemeManager.java](https://github.com/MCMrARM/revolution-irc/blob/master/app/src/main/java/io/mrarm/irc/util/theme/ThemeManager.java)

## Installation

Import [fmind.irctheme](fmind.irctheme) into Revolution IRC settings.
