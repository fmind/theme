# Krita

Fmind color scheme for [Krita](https://krita.org/). Krita reads KDE color schemes, so it uses the shared [KDE Fmind.colors](../gtk/kde/color-schemes/Fmind.colors).

Format: [Krita thememanager.cpp](https://invent.kde.org/graphics/krita/-/blob/master/libs/ui/thememanager.cpp) · [Krita resource folder](https://docs.krita.org/en/reference_manual/resource_management.html)

## Install

1. Copy [Fmind.colors](../gtk/kde/color-schemes/Fmind.colors) into the `color-schemes` folder of Krita's resource folder: `~/.local/share/krita/color-schemes/` on Linux, `%APPDATA%\krita\color-schemes\` on Windows or `~/Library/Application Support/Krita/color-schemes/` on macOS. On Linux, KDE's `~/.local/share/color-schemes/` also works.
2. Restart Krita, then select **Settings → Themes → Fmind**.
