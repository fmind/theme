# Blender

Experimental, partial Fmind preset for Blender. It is not a complete light theme.

Installing a theme preset first resets Blender to its default dark theme, then applies the file. [fmind.xml](fmind.xml) sets only regular buttons, tool buttons and the 3D Viewport background, so menus, headers, panels and the other editors keep the default dark colors. Its keys exist in Blender 5.2; a native session remains unverified.

Format: [Blender_Light.xml](https://projects.blender.org/blender/blender/src/branch/main/scripts/presets/interface_theme/Blender_Light.xml)

## Installation

1. Open Blender and navigate to **Edit → Preferences → Themes**.
2. Click **Install...** in the top-right corner.
3. Select `fmind.xml` and click **Install Theme**.

Use **Reset** in the same panel to return to the default theme.
