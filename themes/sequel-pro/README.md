# Sequel Pro

Fmind light theme for Sequel Pro.

## Installation

1. Double-click `Fmind.spTheme` to install it into Sequel Pro, or copy it to `~/Library/Application Support/Sequel Pro/Themes/Fmind.spTheme`.
2. In Sequel Pro, open **Preferences → Query Editor** and select **Fmind** from the themes menu.
