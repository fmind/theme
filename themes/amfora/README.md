# Fmind for Amfora

Light theme for [Amfora](https://github.com/makeworld-the-better-one/amfora).

Format: [Amfora theme keys](https://github.com/makew0rld/amfora/blob/master/config/theme.go) · [Amfora default-config.toml](https://github.com/makew0rld/amfora/blob/master/default-config.toml)

## Installation

Merge the `[theme]` section of [fmind.toml](fmind.toml) into `~/.config/amfora/config.toml`. It sets the page, tab row, bottom bar, headings, links and text; modals keep Amfora's defaults. Use a light terminal: Amfora draws the focused tab number in white on light terminals but in black on dark ones, which is unreadable on the blue tab.
