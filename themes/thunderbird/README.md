# Thunderbird

Fmind light theme for Mozilla Thunderbird.

## Install

Zip [manifest.json](manifest.json) into `fmind.xpi`. In Thunderbird, open Tools → Add-ons and Themes, click the gear icon, choose **Install Add-on From File...** and select `fmind.xpi`. To try it without installing, load `manifest.json` as a temporary add-on from `about:debugging`.
