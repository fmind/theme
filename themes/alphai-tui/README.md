# Fmind for alphai-tui

Light theme for the [alphai-tui](https://github.com/makeev/alphai-tui) terminal stock dashboard.

Format: [alphai-tui theme slots](https://github.com/makeev/alphai-tui/blob/main/src/theme.rs) · [alphai-tui README](https://github.com/makeev/alphai-tui/blob/main/README.md)

## Installation

Merge the `[theme]` table of [fmind.toml](fmind.toml) into `~/.config/alphai-tui/config.toml`. Use a light terminal background with 24-bit color: text the app does not paint keeps the terminal's colors. A native alphai-tui session remains unverified.
