# Fmind for ColorSlurp

Light palette for [ColorSlurp](https://colorslurp.com/).

Format: [ColorSlurp import formats](https://colorslurp.com/docs/guides/palettes) · [GIMP palettes](https://docs.gimp.org/en/gimp-concepts-palettes.html)

## Installation

ColorSlurp imports GIMP palettes, not JSON. Choose **File** > **Import Palettes** and select [gimp/Fmind.gpl](../gimp/Fmind.gpl), or drop that file into the ColorSlurp window.
