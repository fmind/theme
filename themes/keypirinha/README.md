# Keypirinha

Fmind theme for [Keypirinha](https://keypirinha.com/).

Format: [Keypirinha theming](https://keypirinha.com/theming.html) · [bundled default Keypirinha.ini, 2.26](https://github.com/Keypirinha/Keypirinha/releases/tag/v2.26)

## Install

Merge the `[gui]` and `[theme/Fmind]` sections of [fmind.ini](fmind.ini) into your user `Keypirinha.ini`; the `[gui]` section activates the theme.
