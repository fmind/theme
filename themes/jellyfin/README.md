# Fmind for Jellyfin

Light theme CSS for [Jellyfin](https://jellyfin.org/).

Format: [Jellyfin CSS customization](https://jellyfin.org/docs/general/clients/css-customization/) · [jellyfin-web palette variables](https://github.com/jellyfin/jellyfin-web/blob/master/src/themes/_base/_theme.scss) · [MUI variable prefix](https://github.com/jellyfin/jellyfin-web/blob/master/src/themes/index.ts)

## Installation

1. In Settings → Display, set the theme to **Light**. The stylesheet overrides that theme's palette variables.
2. Paste [fmind.css](fmind.css) into the **Custom CSS** field: Dashboard → Branding for the whole server, or Settings → Display for one user.
