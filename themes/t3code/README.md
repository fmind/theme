# Fmind for T3 Code

Light code editor theme for T3 Code.

Format: [T3 Code themes](https://github.com/pingdotgg/t3code/blob/main/docs/user/appearance.md) · [theme file parser](https://github.com/pingdotgg/t3code/blob/main/apps/web/src/themePalette.ts) · [color roles](https://github.com/pingdotgg/t3code/blob/main/packages/shared/src/themePalettes.ts)

## Installation

On web or desktop, open **Settings → Appearance**, click **Add theme**, and paste or drop [fmind.json](fmind.json). To publish it from a T3 Code server instead, save it as `~/.t3/userdata/themes/fmind.json` and run `t3 theme set fmind`.
