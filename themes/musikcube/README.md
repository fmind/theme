# Fmind for musikcube

Light color theme for [musikcube](https://github.com/clangen/musikcube).

Format: [musikcube bundled themes](https://github.com/clangen/musikcube/blob/master/src/musikcube/data/themes/solarized_light.json) · [theme loader](https://github.com/clangen/musikcube/blob/master/src/musikcube/cursespp/Colors.cpp)

## Installation

Place [fmind.json](fmind.json) in `~/.config/musikcube/themes/`.
