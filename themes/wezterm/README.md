# Fmind for WezTerm

Files: [fmind.toml](fmind.toml).

Format: [WezTerm color scheme files](https://wezterm.org/config/appearance.html#defining-a-color-scheme-in-a-separate-file) · [color.rs](https://github.com/wezterm/wezterm/blob/main/config/src/color.rs)

## Installation

Copy to `~/.config/wezterm/colors/fmind.toml`; set `config.color_scheme = "fmind"` in `wezterm.lua`.
