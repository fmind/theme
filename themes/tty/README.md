# Linux TTY

Fmind color scheme for Linux virtual consoles (TTY).

Format: [console_codes(4)](https://man7.org/linux/man-pages/man4/console_codes.4.html)

## Install

Run `fmind-tty.sh` directly in a virtual terminal or source from your shell initialization (`~/.bashrc`, `~/.zshrc`) when `$TERM = "linux"`.
