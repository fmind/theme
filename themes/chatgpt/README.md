# ChatGPT

Fmind theme for [ChatGPT](https://chatgpt.com/).

Format: [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS) · [Catppuccin ChatGPT userstyle](https://github.com/catppuccin/userstyles/blob/main/styles/chatgpt/catppuccin.user.less)

## Install

Apply `fmind.user.css` via the Stylus browser extension.
