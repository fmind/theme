# Spacemacs

Fmind theme for [Spacemacs](https://www.spacemacs.org/).

Format: [Spacemacs: choosing themes](https://github.com/syl20bnr/spacemacs/blob/develop/doc/DOCUMENTATION.org#choosing-themes) · [Emacs custom themes](https://www.gnu.org/software/emacs/manual/html_node/elisp/Custom-Themes.html)

## Install

1. Copy the Emacs theme, [fmind-theme.el](../emacs/fmind-theme.el), to `~/.emacs.d/private/local/fmind-theme/`.
2. Add `(fmind :location local)` to `dotspacemacs-themes` in `~/.spacemacs`.
