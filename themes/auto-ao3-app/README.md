# Fmind for AutoAO3App

Light stylesheet for [AutoAO3App](https://autoao3app.firebaseapp.com/).

Format: [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS)

## Installation

With the [Stylus](https://github.com/openstyles/stylus) browser extension installed, open the [raw fmind.user.css](https://raw.githubusercontent.com/fmind/theme/main/themes/auto-ao3-app/fmind.user.css) and click **Install style**. The style applies only to `autoao3app.firebaseapp.com`.
