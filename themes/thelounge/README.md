# The Lounge

Fmind theme for [The Lounge](https://thelounge.chat/).

Format: [theme loader](https://github.com/thelounge/thelounge/blob/master/server/plugins/packages/themes.ts) · [client CSS](https://github.com/thelounge/thelounge/blob/master/client/css/style.css)

## Install

On the server, install this directory as a local package, then choose **Fmind** under **Settings** → **Appearance** → **Theme**:

```sh
thelounge install file:/path/to/theme/themes/thelounge
```
