# Sequel Ace

Fmind theme for [Sequel Ace](https://sequel-ace.com/).

Format: [Sequel Ace SPEditorPreferencePane.m](https://github.com/Sequel-Ace/Sequel-Ace/blob/main/Source/Controllers/Preferences/Panes/SPEditorPreferencePane.m) · [bundled themes](https://github.com/Sequel-Ace/Sequel-Ace/tree/main/SharedSupport/Default%20Themes)

## Install

In Sequel Ace, open **Preferences** > **Query Editor** and import `fmind.spTheme` from the themes menu.
