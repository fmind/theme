# Fmind for fzf

Files: [fmind.conf](fmind.conf).

Format: [fzf man page](https://github.com/junegunn/fzf/blob/master/man/man1/fzf.1) · [option parser](https://github.com/junegunn/fzf/blob/master/src/options.go)

## Installation

Copy to `~/.config/fzf/fmind.conf` and set `FZF_DEFAULT_OPTS_FILE="$HOME/.config/fzf/fmind.conf"`.
