# Fmind for CadZinho

Color theme for [CadZinho](https://github.com/zecruel/CadZinho).

Format: [CadZinho config loader](https://github.com/zecruel/CadZinho/blob/opengl/src/gui_config.c)

## Installation

Copy the settings in [fmind.lua](fmind.lua) into `config.lua` in CadZinho's preferences directory (`~/.local/share/CadZinho/CadZinho/` on Linux, `%APPDATA%\CadZinho\CadZinho\` on Windows), then restart CadZinho. It selects the built-in `white` interface preset, a white drawing background and a blue selection highlight; CadZinho has no other custom colors.
