# Fmind for Obsidian

Files: [theme.css](theme.css), [manifest.json](manifest.json).

Format: [Obsidian CSS variables](https://docs.obsidian.md/Reference/CSS+variables/CSS+variables) · [manifest](https://docs.obsidian.md/Reference/Manifest)

## Installation

Copy both into your vault’s `.obsidian/themes/Fmind/`; select Fmind and the Light base color scheme in Appearance.
