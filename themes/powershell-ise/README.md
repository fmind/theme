# PowerShell ISE

Fmind theme for [PowerShell ISE](https://learn.microsoft.com/powershell/scripting/windows-powershell/ise/introducing-the-windows-powershell-ise).

Format: [ISEOptions object](https://learn.microsoft.com/en-us/previous-versions/powershell/scripting/windows-powershell/ise/object-model/the-iseoptions-object)

## Install

Dot-source `fmind.ps1` in your PowerShell ISE profile:

```powershell
. path\to\powershell-ise\fmind.ps1
```
