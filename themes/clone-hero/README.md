# Clone Hero

Fmind theme for [Clone Hero](https://clonehero.net/).

Format: [Color profiles](https://wiki.clonehero.net/books/clone-hero-manual/page/other-custom-content) · [Color profile tags](https://docs.google.com/spreadsheets/d/1b3eyjWoYgs4ikJzUtk0v0qyre10R-ilUTrN9oZbywHI)

## Install

Copy `Fmind.ini` into the `Custom/Colors/` folder of your Clone Hero data folder: `Documents/Clone Hero` on Windows, `~/.clonehero` on Linux or `~/Clone Hero` on macOS. Restart Clone Hero, press Start to open the profile menu, choose **Color Profile** and select **Fmind**. The profile colors guitar and drum lanes with the bright Google colors, which stay visible on the dark highway.
