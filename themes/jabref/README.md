# Fmind for JabRef

Light stylesheet for [JabRef](https://www.jabref.org/).

Format: [JabRef custom themes](https://docs.jabref.org/advanced/custom-themes) · [JabRef 5.15 Base.css](https://github.com/JabRef/jabref/blob/v5.15/src/main/java/org/jabref/gui/Base.css) · [JabRef 6 theme](https://github.com/JabRef/themes.jabref.org/blob/main/themes/JabRef/jabref-theme.css)

## Installation

Select custom CSS in JabRef Preferences → Appearance and choose [fmind.css](fmind.css).
