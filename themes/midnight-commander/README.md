# Midnight Commander

Fmind light skin for Midnight Commander (`mc`).

Format: [mc default skin](https://github.com/MidnightCommander/mc/blob/master/misc/skins/default.ini) · [skin loader](https://github.com/MidnightCommander/mc/blob/master/lib/skin/ini-file.c)

## Installation

1. Copy `fmind.ini` to `~/.local/share/mc/skins/fmind.ini`.
2. In `~/.config/mc/ini`, set `skin=fmind` under `[Midnight-Commander]`.
3. Launch `mc`.
