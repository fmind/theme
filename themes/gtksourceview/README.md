# Fmind for GtkSourceView

Light style scheme for GtkSourceView (used by GNOME Text Editor, gedit, builder, etc.).

Format: [GtkSourceView style scheme reference](https://gnome.pages.gitlab.gnome.org/gtksourceview/gtksourceview5/style-reference.html)

## Installation

Copy [fmind.xml](fmind.xml) to `~/.local/share/gtksourceview-4/styles/` (or `gtksourceview-5/styles/`) and select Fmind in your editor preferences.
