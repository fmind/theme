# Mailspring

Fmind light UI theme for Mailspring.

Format: [Mailspring Theme Starter](https://github.com/Foundry376/Mailspring-Theme-Starter) · [base ui-variables.less](https://github.com/Foundry376/Mailspring/blob/master/app/static/style/base/ui-variables.less)

## Install

In Mailspring, select Edit → Install Theme and select the `mailspring` folder, or copy to `~/.config/Mailspring/packages/`.
