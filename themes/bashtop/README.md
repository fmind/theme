# Bashtop

Fmind theme for [Bashtop](https://github.com/aristocratos/bashtop).

Format: [bashtop themes](https://github.com/aristocratos/bashtop#themes) · [bundled themes](https://github.com/aristocratos/bashtop/tree/master/themes)

## Install

1. Copy `fmind.theme` to `~/.config/bashtop/user_themes/`, where the theme downloader does not overwrite it.
2. Select `*fmind` in Bashtop menu (`Esc` -> `Options` -> `Color theme`).
