# Wolfram Notebooks

Fmind stylesheet for [Wolfram Mathematica / Wolfram Notebooks](https://www.wolfram.com/mathematica/).

Format: [Working with Stylesheets](https://reference.wolfram.com/language/tutorial/WorkingWithStylesheets.html)

## Install

Copy `Fmind.nb` to `SystemFiles/FrontEnd/StyleSheets/` under `$UserBaseDirectory`: `~/.Wolfram/` on Linux, `~/Library/Wolfram/` on macOS or `%APPDATA%\Wolfram\` on Windows (evaluate `$UserBaseDirectory` to confirm). Restart the front end, then select `Format` -> `Stylesheet` -> `Fmind`. To apply it to one notebook without installing, use `Format` -> `Stylesheet` -> `Other...` and select `Fmind.nb`.
