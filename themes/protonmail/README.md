# Protonmail

Fmind theme for [Protonmail](https://proton.me/mail).

Format: [Proton theme variables](https://github.com/ProtonMail/WebClients/blob/main/packages/colors/themes/dist/snow.theme.css)

## Install

Proton Mail has no custom theme setting, so Fmind is a userstyle for the web app.

1. Install the [Stylus](https://github.com/openstyles/stylus) extension.
2. Create a new style in Stylus and paste [fmind.css](fmind.css). Its `@-moz-document` block limits it to `mail.proton.me`.
3. Open Proton Mail. The style overrides the color variables of every Proton theme with Fmind's light colors.
