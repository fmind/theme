# Fmind for iTerm2

Files: [fmind.itermcolors](fmind.itermcolors).

Format: [iTerm2 color presets](https://iterm2.com/documentation-preferences-profiles-colors.html) · [iTerm2 color keys](https://github.com/gnachman/iTerm2/blob/master/sources/Settings/Profiles/ITAddressBookMgr.h)

## Installation

Import through Settings → Profiles → Colors → Color Presets, then select `fmind`.

## Prompt

[Prompt](https://panic.com/prompt/) for Mac imports iTerm2 color presets ([Prompt themes](https://help.panic.com/prompt/prompt-themes/)). In Prompt, open **Settings** → **Themes**, click the gear icon, import [fmind.itermcolors](fmind.itermcolors), then select the imported theme. Prompt for iOS cannot import themes.
