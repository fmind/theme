# Fmind for iTerm2

Files: [fmind.itermcolors](fmind.itermcolors).

Format: [iTerm2 color presets](https://iterm2.com/documentation-preferences-profiles-colors.html) · [iTerm2 color keys](https://github.com/gnachman/iTerm2/blob/master/sources/Settings/Profiles/ITAddressBookMgr.h)

## Installation

Import through Settings → Profiles → Colors → Color Presets, then select `fmind`.
