# Blink Shell

Fmind theme for [Blink Shell](https://blink.sh/).

Format: [Blink fonts and themes](https://github.com/blinksh/blink/blob/raw/Resources/FontsAndThemes.md)

## Install

In Blink Shell, open Settings > Appearance > New Theme, paste the [raw fmind.js](https://raw.githubusercontent.com/fmind/theme/main/themes/blink-shell/fmind.js) URL, download it, then save and select it.
