# Blockbench

Fmind theme for [Blockbench](https://www.blockbench.net/).

Format: [Blockbench light.bbtheme](https://github.com/JannisX11/blockbench/blob/master/themes/light.bbtheme) · [themes.ts](https://github.com/JannisX11/blockbench/blob/master/js/interface/themes.ts)

## Install

In Blockbench, open **File** > **Preferences** > **Theme**, click **Import Theme** and select `Fmind.bbtheme`.
