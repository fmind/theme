# CotEditor

Fmind theme for [CotEditor](https://coteditor.com/).

Format: [CotEditor Theme.swift](https://github.com/coteditor/CotEditor/blob/main/CotEditor/Sources/Models/Theme.swift) · [Customize a theme](https://github.com/coteditor/CotEditor/blob/main/CotEditor/Resources/CotEditor.help/Contents/Resources/en.lproj/pgs/howto_customize_theme.html)

## Install

1. Choose **CotEditor** > **Settings**, then click **Appearance**.
2. Click the **More** button, choose **Import** and select `Fmind.cottheme`, or drag the file into the **Theme** list.
3. Select **Fmind** in the **Theme** list.
