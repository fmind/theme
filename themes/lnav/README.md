# Fmind for lnav

Light theme for [lnav](https://lnav.org/).

Format: [lnav theme definitions](https://docs.lnav.org/en/stable/config.html#theme-definitions) · [lnav config schema](https://lnav.org/schemas/config-v1.schema.json)

## Installation

Copy [fmind.json](fmind.json) to `~/.lnav/configs/installed/fmind.json` and run `:config /ui/theme fmind` in lnav.

The file follows lnav's [theme configuration schema](https://docs.lnav.org/en/stable/config.html#theme-definitions). Native loading and rendering remain unverified here.
