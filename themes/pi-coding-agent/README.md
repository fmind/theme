# Pi Coding Agent

Fmind theme for [Pi Coding Agent](https://github.com/badlogic/pi-mono).

## Install

Copy [fmind.json](fmind.json) to `~/.pi/agent/themes/fmind.json`, then select `fmind` under `/settings` → Theme in Pi. Use a light terminal theme for the surrounding canvas; Pi's theme controls text, borders and message surfaces.

The file follows Pi's [theme schema](https://pi.dev/schemas/theme.schema.json). Native loading and rendering remain unverified here.
