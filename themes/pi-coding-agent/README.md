# Fmind for Pi Coding Agent

Fmind theme for [Pi Coding Agent](https://github.com/earendil-works/pi).

Files: [fmind.json](fmind.json).

Format: [Pi themes](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/themes.md) · [theme schema](https://pi.dev/schemas/theme.schema.json)

## Installation

Copy [fmind.json](fmind.json) to `~/.pi/agent/themes/fmind.json`, then select `fmind` under `/settings` → Theme in Pi (or set `"theme": "fmind"` in `~/.pi/agent/settings.json`). Use a light terminal theme for the surrounding canvas; Pi's theme controls text, borders and message surfaces.

Tested with Pi Coding Agent 1.5.0.
