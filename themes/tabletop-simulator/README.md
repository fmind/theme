# Tabletop Simulator

Fmind theme for [Tabletop Simulator](https://www.tabletopsimulator.com/).

Format: [Tabletop Simulator setUITheme](https://api.tabletopsimulator.com/player/instance/#setuitheme)

## Install

1. In Tabletop Simulator, open `Menu` -> `Configuration` -> `Interface` -> `Theme`.
2. Select a theme, press `Import/Export`, and paste the contents of `fmind.txt`. It sets only buttons, the window background and labels.
