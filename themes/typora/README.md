# Fmind for Typora

Files: [fmind.css](fmind.css).

Format: [Typora: write a custom theme](https://theme.typora.io/doc/Write-Custom-Theme/) · [Typora night.css](https://github.com/typora/typora-default-themes/blob/master/themes/night.css)

## Installation

Preferences → Appearance → Open Theme Folder; copy the CSS, restart Typora, and select Fmind.
