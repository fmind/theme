# SerenityOS

Fmind theme for [SerenityOS](https://serenityos.org/).

Format: [SystemTheme.h](https://github.com/SerenityOS/serenity/blob/master/Userland/Libraries/LibGfx/SystemTheme.h) · [Default.ini](https://github.com/SerenityOS/serenity/blob/master/Base/res/themes/Default.ini)

## Install

Copy `Fmind.ini` to `/res/themes/` in SerenityOS.
