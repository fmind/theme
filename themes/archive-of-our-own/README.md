# Archive of Our Own

Fmind skin for [Archive of Our Own](https://archiveofourown.org/).

Format: [AO3 skin model](https://github.com/otwcode/otwarchive/blob/master/app/models/skin.rb) · [AO3 site CSS](https://github.com/otwcode/otwarchive/tree/master/public/stylesheets/site/2.0)

## Install

Create a new site skin on AO3 and paste `fmind_ao3.css`.
