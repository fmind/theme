# Fmind for Rio

Files: [fmind.toml](fmind.toml).

Format: [Rio config](https://rioterm.com/docs/config) · [Rio colors source](https://github.com/raphamorim/rio/blob/main/rio-vt/src/config/colors/mod.rs)

## Installation

Copy to `~/.config/rio/themes/fmind.toml`; set `theme = "fmind"` in `~/.config/rio/config.toml`. Rio uses `~/.config/rio/` on macOS too.
