# Fmind for Rime

Light color scheme for [Rime](https://rime.im/) input method engine.

Format: [Squirrel squirrel.yaml](https://github.com/rime/squirrel/blob/master/data/squirrel.yaml) · [Weasel weasel.yaml](https://github.com/rime/weasel/blob/master/output/data/weasel.yaml)

## Installation

Merge [fmind.yaml](fmind.yaml) into `squirrel.custom.yaml` or `weasel.custom.yaml`.
