# Fmind for PsychoPy

Light syntax scheme for [PsychoPy](https://www.psychopy.org/).

Format: [PsychoPy bundled theme](https://github.com/psychopy/psychopy-app/blob/dev/src/psychopy_app/themes/spec/PsychopyLight.json) · [theme loader](https://github.com/psychopy/psychopy-app/blob/dev/src/psychopy_app/themes/fonts.py)

## Installation

Copy [fmind.json](fmind.json) to the `themes` folder of the PsychoPy user preferences: `~/.psychopy3/themes/` on Linux and macOS, or `%APPDATA%\psychopy3\themes\` on Windows. The **Themes** menu of the Builder or Coder opens this folder with **Open theme folder**. Restart PsychoPy, then select **fmind** in the **Themes** menu.
