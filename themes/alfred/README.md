# Fmind Alfred

Clean, minimalist light theme for Alfred on macOS.

Format: [Alfred Appearance](https://www.alfredapp.com/help/appearance/) · [exported Alfred theme](https://github.com/dracula/alfred/blob/master/Dracula.alfredappearance)

## Install

1. Double-click [fmind.alfredappearance](fmind.alfredappearance) in Finder, or drag it into Alfred Preferences.
2. In **Alfred Preferences** → **Appearance**, select **Fmind** from the list of themes.
