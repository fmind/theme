# Starship Powerline Preset

Fmind Powerline preset for [Starship](https://starship.rs/).

Format: [Starship configuration](https://starship.rs/config/)

## Install

Back up your existing `~/.config/starship.toml`, then copy [starship.toml](starship.toml) there. The prompt uses Powerline and Nerd Font glyphs, so the terminal needs a [Nerd Font](https://www.nerdfonts.com/).
