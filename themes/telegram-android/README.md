# Telegram Android

Fmind light theme for Telegram on Android.

Format: [Telegram Android ThemeColors.java](https://github.com/DrKLO/Telegram/blob/master/TMessagesProj/src/main/java/org/telegram/ui/ActionBar/ThemeColors.java) · [attheme parser](https://github.com/DrKLO/Telegram/blob/master/TMessagesProj/src/main/java/org/telegram/ui/ActionBar/Theme.java)

## Installation

1. Send `fmind.attheme` to your Telegram chat or Saved Messages.
2. Tap the file in chat and choose **Apply Theme**.
