# Ripcord

Fmind theme for [Ripcord](https://cancel.fm/ripcord/).

Format: [Ripcord theme keys (author's gist)](https://gist.github.com/randrew/81d4fed3ef72e56bb3d24bf2a564225c/14d5efc287b246f8dd1f01958274f2957d78e7c9) · [Ripcord changelog](https://dev.cancel.fm/changelog)

## Install

Copy the contents of `fmind.json`, then in Ripcord **Preferences** click **Customize** beside the color theme and choose **Paste from JSON** in the Theme Editor.
