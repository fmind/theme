# Spicetify

Fmind theme for [Spicetify](https://spicetify.app/).

Format: [Spicetify color.ini](https://github.com/spicetify/cli/blob/main/Themes/SpicetifyDefault/color.ini) · [color.go](https://github.com/spicetify/cli/blob/main/src/utils/color.go)

## Install

1. Copy `color.ini` into your Spicetify theme folder (`~/.config/spicetify/Themes/Fmind/`).
2. Run:
```sh
spicetify config current_theme Fmind
spicetify apply
```
