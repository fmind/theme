# Inkscape

Fmind color palette for [Inkscape](https://inkscape.org/).

Format: [Inkscape palettes (GIMP .gpl)](https://gitlab.com/inkscape/inkscape/-/blob/master/share/palettes/README) · [Inkscape palette manual](https://inkscape-manuals.readthedocs.io/en/latest/palette.html)

## Install

1. Copy `fmind.gpl` to your Inkscape palettes directory (`~/.config/inkscape/palettes/` on Linux).
2. In Inkscape, click the arrow on the bottom palette bar and select **Fmind**.
