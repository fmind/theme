# Fmind for man pages

Light theme highlighting for manual pages rendered with `less`.

Files: [fmind.sh](fmind.sh).

Format: [less(1) LESS_TERMCAP_xx](https://man7.org/linux/man-pages/man1/less.1.html) · [grotty(1) GROFF_NO_SGR](https://man7.org/linux/man-pages/man1/grotty.1.html)

## Installation

Copy [fmind.sh](fmind.sh) to `~/.config/man-pages/fmind.sh` and source it in `~/.bashrc` or `~/.zshrc`:

```sh
. "$HOME/.config/man-pages/fmind.sh"
```
