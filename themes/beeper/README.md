# Fmind for Beeper

Light theme for Beeper desktop client.

Format: [Beeper themes: variables.css](https://github.com/beeper/themes/blob/main/current-v4/variables.css) · [Custom CSS instructions](https://github.com/beeper/themes#how-to-use-themes)

## Installation

In Beeper Desktop, open **Settings** → **Appearance**, scroll to **Custom CSS** and click **Open CSS file in editor**. Replace the file's contents with [fmind.css](fmind.css), save, then click **Reload CSS**. The theme changes only the light appearance.
