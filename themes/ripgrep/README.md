# Fmind for ripgrep

Light theme configuration for [ripgrep](https://github.com/BurntSushi/ripgrep).

## Installation

Set the `RIPGREP_CONFIG_PATH` environment variable in your shell profile:

```sh
export RIPGREP_CONFIG_PATH="$HOME/.config/ripgrep/fmind.ripgreprc"
```

Or append the flags from [fmind.ripgreprc](fmind.ripgreprc) to your existing ripgrep configuration file.
