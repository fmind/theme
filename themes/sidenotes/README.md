# SideNotes

Fmind theme for [SideNotes](https://www.apptorium.com/sidenotes).

Format: [sntheme schema](https://www.apptorium.com/schemas/sntheme.json) · [Creating themes](https://www.apptorium.com/sidenotes/articles/creating-themes) · [SideNotes-Themes](https://github.com/Apptorium/SideNotes-Themes)

## Install

Double-click `Fmind.sntheme` to copy it into SideNotes, then choose **Fmind** from the **Theme** menu in **Preferences → Appearance**.
