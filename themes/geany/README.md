# Fmind for Geany

Files: [fmind.conf](fmind.conf).

Format: [Geany color schemes](https://www.geany.org/manual/current/index.html#color-schemes-menu) · [named styles](https://github.com/geany/geany/blob/master/data/filedefs/filetypes.common)

## Installation

Copy to `~/.config/geany/colorschemes/fmind.conf`; choose View → Change Color Scheme → Fmind. Covers shared language styles and editor decorations.
