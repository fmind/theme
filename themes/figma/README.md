# Figma

Fmind color tokens for Figma.

Format: [Tokens Studio token format](https://docs.tokens.studio/manage-settings/token-format) · [file loader](https://github.com/tokens-studio/figma-plugin/blob/main/packages/tokens-studio-for-figma/src/app/components/PresetProvider/FilePreset.tsx)

## Installation

1. Install the [Tokens Studio for Figma](https://tokens.studio/) plugin.
2. In the plugin, choose **Load from file/folder or preset**, then **Choose file**, and select `tokens.json`. It loads one token set named Fmind.
3. Open **Styles & Variables** to create Figma color styles or variables from that set.
