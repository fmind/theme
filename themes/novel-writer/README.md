# Fmind for novelWriter

Light theme for [novelWriter](https://novelwriter.io/) 26.2 and later, which reads TOML color themes.

Format: [bundled default_light.toml](https://github.com/saga-soft/novelWriter/blob/main/novelwriter/assets/themes/default_light.toml) · [theme loader](https://github.com/saga-soft/novelWriter/blob/main/novelwriter/gui/theme.py)

## Installation

Copy [fmind.toml](fmind.toml) to the `themes` folder in novelWriter's application data location, which novelWriter creates on first start:

- Linux: `~/.local/share/novelwriter/themes/`
- macOS: `~/Library/Application Support/novelwriter/themes/`
- Windows: `C:\Users\<USER>\AppData\Roaming\novelwriter\themes\`

Restart novelWriter and select **Fmind** as the light colour theme in Preferences.
