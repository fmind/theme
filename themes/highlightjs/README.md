# Fmind Highlight.js

A high-contrast light theme stylesheet for highlight.js syntax highlighting.

## Install

Link [fmind.css](fmind.css) in your HTML document:

```html
<link rel="stylesheet" href="path/to/fmind.css">
<script src="path/to/highlight.min.js"></script>
<script>hljs.highlightAll();</script>
```
