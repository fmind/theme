# Fmind for Ghostty

Files: [fmind](fmind).

Format: [Ghostty config reference](https://ghostty.org/docs/config/reference) · [custom themes](https://ghostty.org/docs/features/theme)

## Installation

Requires Ghostty 1.2.0 or later, which added `faint-opacity`; older versions report it as an unknown key.

Copy to `~/.config/ghostty/themes/fmind`; set `theme = fmind`.
