# Fmind for Fuzzel

Files: [fmind.ini](fmind.ini).

## Installation

Merge fragments into existing settings.

Copy to `~/.config/fuzzel/fmind.ini`; add `include=~/.config/fuzzel/fmind.ini` before any section in `~/.config/fuzzel/fuzzel.ini`, or merge the `[colors]` section. Set `font=Google Sans` in the default section if desired. Covers all twelve color roles with opaque RGBA values.
