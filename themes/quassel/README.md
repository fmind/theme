# Quassel

Fmind theme for [Quassel IRC](https://quassel-irc.org/).

Format: [Quassel QssParser](https://github.com/quassel/quassel/blob/master/src/uisupport/qssparser.cpp) · [bundled stylesheets](https://github.com/quassel/quassel/tree/master/data/stylesheets)

## Install

1. Copy `Fmind.qss` to `~/.config/quassel-irc.org/stylesheets/` (or your Quassel data directory).
2. In Settings → Configure Quassel → Interface, check **Use custom stylesheet** and select `Fmind.qss`.
