# Fmind for Sioyek

Light color scheme for [Sioyek](https://sioyek.info/).

Format: [sioyek config.cpp](https://github.com/ahrm/sioyek/blob/development/pdf_viewer/config.cpp) · [prefs.config](https://github.com/ahrm/sioyek/blob/development/pdf_viewer/prefs.config)

## Installation

Append [fmind.config](fmind.config) to `~/.config/sioyek/prefs_user.config` on Linux or macOS, or to `prefs_user.config` next to `sioyek.exe` for the portable Windows build. Restart sioyek.
