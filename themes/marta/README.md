# Fmind for Marta

Light theme for [Marta](https://marta.sh/), the macOS file manager. Files: [Fmind.theme](Fmind.theme).

Format: [Marta themes](https://marta.sh/docs/configuration/themes/) · [Marta 0.8.2 bundled themes (`Marta.app/Contents/Resources/Themes/Classic.theme`)](https://updates.marta.sh/release/Marta-0.8.2.dmg)

## Installation

Copy [Fmind.theme](Fmind.theme) to `~/Library/Application Support/org.yanex.marta/Themes/`, then run the _Switch Theme_ action and pick Fmind, or set `theme "Fmind"` in the `behavior` block of your Marta configuration. The theme covers the file panes, tabs, search bar, status bar and built-in text editor. The embedded terminal's palette comes from a separate `.ettyTheme` file, which this port does not ship.
