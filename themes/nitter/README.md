# Fmind for Nitter

Light theme CSS for [Nitter](https://github.com/zedeus/nitter).

## Installation

On a Nitter instance you host, copy [fmind.css](fmind.css) to `css/themes/` in the static directory (`public/` by default), then choose **Fmind** under Preferences → Theme. Nitter lists every file in that folder as a theme. On other instances, apply the same file with Stylus for the instance's domain.
