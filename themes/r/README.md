# Fmind for R

Color palette vectors for R.

Format: [R palette()](https://stat.ethz.ch/R-manual/R-devel/library/grDevices/html/palette.html) · [R color strings](https://stat.ethz.ch/R-manual/R-devel/library/grDevices/html/col2rgb.html) · [R source()](https://stat.ethz.ch/R-manual/R-devel/library/base/html/source.html)

## Installation

Source [fmind.R](fmind.R) in your R session.
