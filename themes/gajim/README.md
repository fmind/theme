# Gajim

Fmind theme for [Gajim](https://gajim.org/). It colors conversation text, nicknames, status messages, the chat banner and status indicators; the rest of the window follows Gajim's light appearance.

Format: [Gajim theme options](https://github.com/gajim/gajim/blob/master/src/gajim/gtk/themes.py) · [theme loader](https://github.com/gajim/gajim/blob/master/src/gajim/gtk/css_config.py)

## Install

1. Copy `fmind.css` to Gajim's `theme` folder: `~/.config/gajim/theme/fmind.css` on Linux or `%APPDATA%\Gajim\theme\fmind.css` on Windows.
2. Restart Gajim, then open Preferences → Style, set Dark Theme to disabled and select `fmind` under Theme.
