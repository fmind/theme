# Roam Research

Fmind theme for [Roam Research](https://roamresearch.com/).

Format: [Roam site.css selectors](https://roamresearch.com/assets/css/less-compiled/site.css) · [Roam app (roam/css loader)](https://roamresearch.com/js/compiled/main.js)

## Install

1. In Roam Research, create or open your `[[roam/css]]` page.
2. Create a code block set to CSS.
3. Paste the contents of `fmind.css` into the block.
