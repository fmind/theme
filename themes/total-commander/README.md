# Total Commander

Fmind light theme for Total Commander.

Format: [wincmd.ini Colors](https://www.ghisler.ch/wiki/index.php?title=Wincmd.ini#Colors)

## Install

Merge the `[Colors]` section into your `wincmd.ini` (typically located in `%APPDATA%\GHISLER\wincmd.ini` or the Total Commander install directory).
