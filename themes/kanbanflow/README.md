# Fmind for KanbanFlow

Light stylesheet for [KanbanFlow](https://kanbanflow.com/).

## Installation

1. Install the [Stylus](https://github.com/openstyles/stylus) extension.
2. Create a new style in Stylus and paste [fmind.user.css](fmind.user.css). Its `@-moz-document` block limits it to `kanbanflow.com`.
3. Open KanbanFlow.
