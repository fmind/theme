# Fmind for Notepad++

Files: [fmind.xml](fmind.xml).

Format: [Notepad++ user manual: Themes](https://npp-user-manual.org/docs/themes/) · [stylers.model.xml](https://github.com/notepad-plus-plus/notepad-plus-plus/blob/master/PowerEditor/src/stylers.model.xml)

## Installation

Copy to `%APPDATA%\Notepad++\themes\` (or the portable installation’s `themes/`); restart, then Settings → Style Configurator → Fmind. Use light mode; disable Global override colors so lexer styles apply. Covers 58 native lexers, editor decorations and tabs.

Lexer identifiers follow the [native style definitions](https://github.com/notepad-plus-plus/notepad-plus-plus/blob/master/PowerEditor/src/stylers.model.xml). Native loading and rendering on Windows remain unverified here.
