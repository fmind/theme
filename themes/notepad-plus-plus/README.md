# Fmind for Notepad++

Files: [fmind.xml](fmind.xml).

## Installation

Merge fragments into existing settings.

Copy to `%APPDATA%\Notepad++\themes\` (or the portable installation’s `themes/`); restart, then Settings → Style Configurator → Fmind. Use light mode; disable Global override colors so lexer styles apply. Covers 60 lexers, editor decorations and tabs.
