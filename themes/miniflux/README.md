# Fmind for Miniflux

Custom stylesheet for [Miniflux](https://miniflux.app/).

Format: [Miniflux light theme variables](https://github.com/miniflux/v2/blob/main/internal/ui/static/css/light.css) · [Custom CSS loading](https://github.com/miniflux/v2/blob/main/internal/template/templates/common/layout.html)

## Installation

Paste [fmind.css](fmind.css) into Miniflux Settings → Custom CSS.
