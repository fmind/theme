# Fmind for VS Code

Files: [theme](fmind-color-theme.json), [manifest](package.json).

## Installation

Configuration destinations are relative to `~/.config` unless an absolute path or another location is specified. Merge fragments into existing settings.

Copy the whole this directory folder to `~/.vscode/extensions/fmind-theme-3.0.0/`, reload VS Code, then select `fmind` in Preferences: Color Theme.
