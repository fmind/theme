# Fmind for Atuin

Files: [fmind.toml](fmind.toml).

Format: [Atuin theming](https://docs.atuin.sh/latest/guide/theming/) · [Atuin theme.rs](https://github.com/atuinsh/atuin/blob/main/crates/atuin-client/src/theme.rs)

## Installation

Copy to `~/.config/atuin/themes/fmind.toml`; set `[theme] name = "fmind"` in `~/.config/atuin/config.toml`.
