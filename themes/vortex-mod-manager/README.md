# Fmind for Vortex Mod Manager

Light theme for [Vortex Mod Manager](https://www.nexusmods.com/site/mods/1).

## Installation

Vortex loads a theme from a folder that holds `variables.scss`. Copy [variables.scss](variables.scss) to `%APPDATA%\Vortex\themes\Fmind\variables.scss`, restart Vortex, then select **Fmind** under **Settings** → **Theme**.
