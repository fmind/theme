# Fmind for TablePlus

Theme for [TablePlus](https://tableplus.com/).

Format: [TablePlus built-in themes](https://github.com/TablePlus/TablePlus-Themes/blob/main/themes/sunset-light.json) · [TablePlus Fonts & Themes](https://tableplus.com/docs/preferences/fonts-and-colors)

## Installation

Open **Settings → Fonts & Themes** in TablePlus (`Cmd+,` on macOS, `Ctrl+,` on Windows and Linux), click **Add theme…** below the theme list, choose **File or folder…**, select [fmind.json](fmind.json), then select **Fmind**.
