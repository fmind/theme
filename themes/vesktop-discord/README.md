# Vesktop Discord

Fmind theme for [Vesktop Discord](https://github.com/Vencord/Vesktop).

Format: [Vencord theme header parser](https://github.com/Vendicated/Vencord/blob/main/src/main/themes/index.ts)

## Install

Copy `fmind.theme.css` to your Vesktop/Vencord `themes/` directory and enable in Themes settings. Then choose **Light** under Discord's Appearance settings, because the theme only restyles the light theme.
