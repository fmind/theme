# Fmind for BetterCanvas

Light preset for [BetterCanvas](https://github.com/UseBetterCanvas/bettercanvas) extension.

Format: [BetterCanvas theme import](https://github.com/UseBetterCanvas/bettercanvas/blob/main/js/popup.js)

## Installation

Open the BetterCanvas popup, go to **Themes**, and paste the contents of [fmind.txt](fmind.txt) into **Copy and paste exported themes here**. It turns on the custom colors and sets white backgrounds, charcoal text, blue links and palette card colors.
