# Fmind for Base16

Fmind light theme for Base16 builders and applications.

Files: [fmind.yaml](fmind.yaml).

Format: [Tinted Theming scheme spec](https://github.com/tinted-theming/home/blob/main/builder.md#schemes) · [Base16 styling](https://github.com/tinted-theming/home/blob/main/styling.md)

## Installation

Copy `fmind.yaml` to your Base16 templates or schemes directory (such as `~/.config/base16/schemes/`).
