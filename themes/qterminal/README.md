# Fmind for QTerminal

Files: [fmind.colorscheme](fmind.colorscheme).

Format: [qtermwidget ColorScheme.cpp](https://github.com/lxqt/qtermwidget/blob/master/lib/ColorScheme.cpp) · [bundled color schemes](https://github.com/lxqt/qtermwidget/tree/master/lib/color-schemes) · [QTerminal scheme folders](https://github.com/lxqt/qterminal/blob/master/src/mainwindow.cpp)

## Installation

Copy to `~/.local/share/qterminal/color-schemes/` (`$XDG_DATA_HOME/qterminal/color-schemes/` if set); restart, then File → Preferences → Appearance → Color scheme → fmind. Older versions also search `~/.config/qterminal/color-schemes/` beside their config file.
