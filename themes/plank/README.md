# Plank

Fmind theme for [Plank](https://launchpad.net/plank) dock.

Format: [Plank theme loader](https://github.com/zquestz/plank-reloaded/blob/master/lib/Drawing/Theme.vala) · [bundled Matte-Light theme](https://github.com/zquestz/plank-reloaded/blob/master/data/themes/Matte-Light/dock.theme)

## Install

1. Copy the `Fmind` folder to `~/.local/share/plank/themes/`.
2. Open Plank preferences (`plank --preferences`) and select **Fmind**.
