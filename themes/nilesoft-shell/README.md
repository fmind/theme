# Fmind for Nilesoft Shell

Light theme for [Nilesoft Shell](https://nilesoft.org/).

Format: [Nilesoft Shell themes](https://nilesoft.org/docs/configuration/themes) · [bundled theme.nss](https://github.com/moudey/Shell/blob/main/src/bin/imports/theme.nss)

## Installation

Copy [fmind.nss](fmind.nss) to the `imports` folder, then in `shell.nss` replace the bundled `import 'imports/theme.nss'` line with `import 'imports/fmind.nss'`, so only one `theme {}` block applies.
