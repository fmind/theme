# ghostwriter

Fmind theme for [ghostwriter](https://ghostwriter.kde.org/).

Format: [ghostwriter theme loader](https://invent.kde.org/office/ghostwriter/-/blob/master/src/theme/themerepository.cpp)

## Install

Copy `Fmind.json` into your ghostwriter themes directory (`~/.local/share/ghostwriter/themes/`) and select Fmind in Settings.
