# Fmind for lsd

Files: [fmind.yaml](fmind.yaml).

Format: [lsd colors-sample.yaml](https://github.com/lsd-rs/lsd/blob/main/doc/samples/colors-sample.yaml) · [ColorTheme in color.rs](https://github.com/lsd-rs/lsd/blob/main/src/theme/color.rs)

## Installation

Copy to `~/.config/lsd/colors.yaml`; set `color.theme: custom` in `~/.config/lsd/config.yaml`.
