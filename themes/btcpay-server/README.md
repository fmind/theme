# Fmind for BTCPay Server

Light theme for [BTCPay Server](https://btcpayserver.org/).

Format: [BTCPay theme docs](https://docs.btcpayserver.org/Development/Theme/) · [default.css](https://github.com/btcpayserver/btcpayserver/blob/master/BTCPayServer/wwwroot/main/themes/default.css)

## Installation

Upload [fmind.css](fmind.css) as a custom theme on the **Server Settings** → **Branding** page. It overrides the default light theme's variables.
