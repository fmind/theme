# Fmind for Misskey

Light theme for [Misskey](https://misskey-hub.net/).

Format: [Misskey light base theme](https://github.com/misskey-dev/misskey/blob/develop/packages/frontend-shared/themes/_light.json5) · [theme validation](https://github.com/misskey-dev/misskey/blob/develop/packages/frontend-shared/js/theme.ts)

## Installation

Install [fmind.json](fmind.json) in Misskey Settings → Themes.
