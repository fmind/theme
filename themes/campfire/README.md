# Fmind for Campfire

Light theme for Campfire chat.

Format: [Campfire colors.css](https://github.com/basecamp/once-campfire/blob/main/app/assets/stylesheets/colors.css) · [Custom styles](https://github.com/basecamp/once-campfire/blob/main/app/views/accounts/custom_styles/edit.html.erb)

## Installation

As a Campfire administrator, open **Account settings** > **Custom styles**, paste [fmind.css](fmind.css) and save. The styles apply to everyone on that Campfire. Use a light system appearance: in dark mode Campfire inverts its icons, which then disappear on the white background.
