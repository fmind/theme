# Fmind for TextMate

Files: [fmind.tmTheme](fmind.tmTheme).

Format: [TextMate themes](https://macromates.com/manual/en/themes)

## Installation

Open the file with TextMate 2 to install; select Fmind in Preferences → Fonts & Colors. Includes a light theme identity, editor colors, syntax and diff scopes.

## Textastic

[Textastic](https://www.textasticapp.com/) reads TextMate themes ([Textastic customization](https://www.textasticapp.com/v10/manual/customization/custom_syntax_themes_templates.html)).

1. In Textastic's Local Files root, create a folder named `#Textastic` (case-sensitive).
2. Copy [fmind.tmTheme](fmind.tmTheme) into it.
3. Open **Settings** → **Other** → **Reload Customizations**, then select Fmind in the code editor settings.
