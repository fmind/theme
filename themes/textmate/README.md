# Fmind for TextMate

Files: [fmind.tmTheme](fmind.tmTheme).

Format: [TextMate themes](https://macromates.com/manual/en/themes)

## Installation

Open the file with TextMate 2 to install; select Fmind in Preferences → Fonts & Colors. Includes a light theme identity, editor colors, syntax and diff scopes.
