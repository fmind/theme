# Fmind for Facebook

Userstyle for Facebook.

Format: [Stylus Mozilla-format import](https://github.com/openstyles/stylus/blob/master/src/edit.html) · [facebook.com light-mode variables](https://www.facebook.com/login/)

## Installation

In Stylus, choose **Write new style**, click **Import**, and paste [fmind.css](fmind.css) as Mozilla-format code. Its `@-moz-document domain("facebook.com")` block limits it to Facebook. Light mode only.
