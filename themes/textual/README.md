# Textual

Fmind theme for [Textual](https://www.textualapp.com/) on macOS.

Format: [bundled Simplified style](https://github.com/blendbyte/Textual/tree/main/App/Resources/Styling/Bundled%20Styles/Simplified) · [message template](https://github.com/blendbyte/Textual/blob/main/App/Resources/Styling/Style%20Default%20Templates/Version%204/newMessagePostedWithSender.mustache) · [styles folder](https://github.com/blendbyte/Textual/blob/main/App/Sources/Support/TPCPathInfo.m)

## Install

1. Copy `design.css` to `~/Library/Application Support/Textual/Styles/Fmind/`.
2. Select **Fmind** in Textual Preferences (`Preferences` -> `Style`).
