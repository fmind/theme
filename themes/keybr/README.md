# Fmind for Keybr

Userstyle for [Keybr](https://www.keybr.com/).

Format: [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS) · [Keybr light theme variables](https://github.com/aradzie/keybr.com/blob/master/packages/keybr-themes/lib/themes/theme-1-light.less)

## Installation

1. Install the [Stylus](https://github.com/openstyles/stylus) extension.
2. Create a new style in Stylus and paste [fmind.user.css](fmind.user.css). Its `@-moz-document` block limits it to `keybr.com`.
3. Open Keybr and choose its Light theme. The style recolors every built-in theme, but some other themes add their own background images.
