# Fmind Steam

A clean light theme for the Steam client interface using the Fmind color scheme.

## Install

1. Install the [Millennium](https://steambrew.app/) client patcher ([source](https://github.com/SteamClientHomebrew/Millennium)) to enable custom CSS styling.
2. Copy [skin.json](skin.json) and [webkit.css](webkit.css) into a `Fmind/` folder under `millennium/themes/` in your Steam directory (for example `~/.steam/steam/millennium/themes/Fmind/` on Linux); Millennium only lists theme folders that contain `skin.json`.
3. Select **Fmind** in the theme picker and restart Steam.
