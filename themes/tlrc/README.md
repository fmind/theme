# Fmind for tlrc

Light theme for [tlrc](https://github.com/tldr-pages/tlrc).

## Installation

Merge [fmind.toml](fmind.toml) into the config file printed by `tldr --config-path` (`~/.config/tlrc/config.toml` on Linux).

The theme uses ANSI color names, so it takes the Fmind colors from your terminal palette; descriptions keep the terminal's default foreground. Install the Fmind theme for your terminal first.
