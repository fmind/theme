# TeXShop

Fmind theme for [TeXShop](https://pages.uoregon.edu/koch/texshop/).

Format: [TeXShop theme loader](https://pages.uoregon.edu/koch/texshop/texshop-64/texshopsource.zip) (`Sources/TSColorSupport.m` and the bundled `Resources/TeXShop/Themes/LiteTheme.plist`) · [Themes release notes](https://pages.uoregon.edu/koch/texshop/changes_3.html)

## Install

Copy `Fmind.plist` to `~/Library/TeXShop/Themes/`. In TeXShop Settings, open the **Themes** tab and choose **Fmind** as the lite theme. The theme uses the same color keys as TeXShop's bundled LiteTheme.
