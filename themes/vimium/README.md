# Vimium

Fmind light theme for Vimium.

Format: [Vimium vomnibar_page.css](https://github.com/philc/vimium/blob/master/pages/vomnibar_page.css) · [Vimium hint CSS default](https://github.com/philc/vimium/blob/master/lib/settings.js)

## Install

In Chrome or Firefox, open the Vimium Options page, expand **Advanced Options**, and paste the contents of `fmind.css` into **CSS for Vimium UI**.
