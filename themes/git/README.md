# Git

Fmind light theme for Git CLI output (`git diff`, `git status`, `git branch`).

Format: [git-config color](https://git-scm.com/docs/git-config#Documentation/git-config.txt-color)

## Install

Include `fmind.gitconfig` from your global `~/.gitconfig`:

```ini
[include]
	path = /path/to/theme/themes/git/fmind.gitconfig
```
