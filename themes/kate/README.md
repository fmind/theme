# Fmind for Kate

Files: [fmind.theme](fmind.theme).

Format: [Kate color themes](https://docs.kde.org/stable_kf6/en/kate/katepart/color-themes.html) · [KSyntaxHighlighting themes](https://invent.kde.org/frameworks/syntax-highlighting/-/blob/master/data/themes/breeze-light.theme)

## Installation

Settings → Configure Kate → Color Themes → Import. Select Fmind. Also usable by KSyntaxHighlighting applications.
