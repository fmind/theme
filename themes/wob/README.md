# Fmind for WOB

Files: [fmind.ini](fmind.ini).

Format: [wob.ini(5)](https://github.com/francma/wob/blob/master/wob.ini.5.scd)

## Installation

Merge the six root-level color settings into `~/.config/wob/wob.ini`, or launch your existing WOB pipeline with `wob --config /path/to/fmind.ini`. Includes overflow colors; geometry and bindings remain in your configuration.
