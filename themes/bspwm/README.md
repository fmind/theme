# Fmind for bspwm

Files: [fmind.sh](fmind.sh).

Format: [bspwm(1)](https://github.com/baskerville/bspwm/blob/master/doc/bspwm.1.asciidoc)

## Installation

Copy to `~/.config/bspwm/fmind.sh`; source with `. "$HOME/.config/bspwm/fmind.sh"` near the end of `bspwmrc`. Colors window borders and preselection feedback.
