# Fmind for Neiki's Page Editor

Light theme for [Neiki's Page Editor](https://github.com/neikiri/neiki-page-editor) chrome: toolbar, status bar, canvas frame and focus ring.

Format: [custom theme CSS](https://github.com/neikiri/neiki-page-editor#custom-theme-css) · [editor CSS variables](https://github.com/neikiri/neiki-page-editor/blob/main/src/neiki-page-editor.css)

## Installation

Load [fmind.css](fmind.css) in the page that hosts the editor, for example `<link rel="stylesheet" href="fmind.css">`, and keep the editor on its default `light` theme.
