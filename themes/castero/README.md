# Fmind for Castero

Light color scheme for [Castero](https://github.com/xgi/castero).

Format: [castero.conf template](https://github.com/xgi/castero/blob/master/castero/templates/castero.conf)

## Installation

Merge the `[colors]` keys from [fmind.conf](fmind.conf) into `~/.config/castero/castero.conf`. Use a 256-color terminal with the Fmind palette: text and background follow the terminal defaults, and selected items use white (index 231) on ANSI blue.
