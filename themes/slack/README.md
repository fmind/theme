# Fmind for Slack

A light theme for Slack workspace sidebars.

## Installation

1. Copy the values below or from [fmind.txt](fmind.txt):
   ```text
   #ffffff,#f1f3f4,#174ea6,#ffffff,#d2e3fc,#202124,#34a853,#a50e0e
   ```
2. In Slack, click your profile picture and select **Preferences**.
3. In the Preferences menu, choose **Themes**.
4. In the **Color mode** section, ensure Light appearance is enabled.
5. Click **Create custom theme** or **Import**.
6. Paste the comma-separated hex string into the theme input.
