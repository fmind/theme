# Fmind for Slack

A light theme for Slack workspace sidebars.

Format: [Slack: Change your Slack theme](https://slack.com/help/articles/205166337-Change-your-Slack-theme)

## Installation

1. Copy the values below or from [fmind.txt](fmind.txt):
   ```text
   #ffffff,#f1f3f4,#174ea6,#ffffff,#d2e3fc,#202124,#34a853,#a50e0e
   ```
2. In the Slack desktop app, click your profile picture and select **Preferences**.
3. Click **Appearance**, then select **Custom theme**.
4. Next to **Theme Colors**, click **Import theme**, then **Paste your legacy theme colors**.
5. Paste the comma-separated hex string and click **Apply**.
