# Cava

Fmind theme for [Cava](https://github.com/karlstav/cava).

Format: [Cava example config](https://github.com/karlstav/cava/blob/master/example_files/config) · [bundled themes](https://github.com/karlstav/cava/tree/master/output/themes)

## Install

[config](config) is a `[color]` section. With Cava 0.10.5 or later, copy it to `~/.config/cava/themes/fmind` and set `theme = 'fmind'` in the `[color]` section of `~/.config/cava/config`. With older versions, copy its `[color]` section into `~/.config/cava/config`.
