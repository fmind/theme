# Fmind for Warp

Files: [fmind.yaml](fmind.yaml).

Format: [Warp custom themes](https://docs.warp.dev/terminal/appearance/custom-themes)

## Installation

Copy `fmind.yaml` to `~/.warp/themes/fmind.yaml` on macOS, `~/.local/share/warp-terminal/themes/fmind.yaml` on Linux (`$XDG_DATA_HOME/warp-terminal/themes/fmind.yaml` if set), or `%APPDATA%\warp\Warp\data\themes\fmind.yaml` on Windows. Restart if needed and select Fmind in Appearance → Themes.
