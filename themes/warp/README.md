# Fmind for Warp

Files: [fmind.yaml](fmind.yaml).

Format: [Warp custom themes](https://docs.warp.dev/terminal/appearance/custom-themes)

## Installation

Copy to `~/.warp/themes/` on macOS, `~/.local/share/warp-terminal/themes/` on Linux (`$XDG_DATA_HOME` if set), or `%APPDATA%\warp\Warp\data\themes\` on Windows. Restart if needed and select Fmind in Appearance → Themes.
