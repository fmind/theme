# MindNode

Fmind theme for [MindNode](https://mindnode.com/).

Format: [MindNode static themes](https://mindnode.com/themes) (`.mindnodetheme` ZIP archives holding `contents.xml` and `metadata.plist`)

## Install

1. Package the theme on your Mac:

   ```sh
   cd fmind.mindnodetheme
   zip -0 -X ~/Downloads/Fmind.mindnodetheme contents.xml metadata.plist
   ```

2. Double-click `~/Downloads/Fmind.mindnodetheme` to import it into MindNode.
3. Select **Fmind** in MindNode's theme picker.
