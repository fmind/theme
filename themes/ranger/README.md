# ranger

Fmind light colorscheme for ranger file manager.

Format: [ranger colorschemes](https://github.com/ranger/ranger/blob/master/doc/colorschemes.md) · [ranger loader](https://github.com/ranger/ranger/blob/master/ranger/gui/colorscheme.py)

## Install

Copy `fmind.py` to `~/.config/ranger/colorschemes/fmind.py`, then set `set colorscheme fmind` in `~/.config/ranger/rc.conf`.
