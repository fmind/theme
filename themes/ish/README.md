# iSH

Fmind theme for [iSH](https://ish.app/).

Format: [iSH theme loader](https://github.com/ish-app/ish/blob/master/app/Theme.m)

## Install

Save `Fmind.json` to Files, then in iSH open Settings → Appearance → Theme, tap **Import Theme** and choose the file. The file name becomes the theme name, and the theme keeps the iOS interface light. iSH stores user themes in the `themes` folder of its documents directory.
