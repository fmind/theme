# Fmind for DuckDuckGo

Fmind light theme for DuckDuckGo.

Format: [DuckDuckGo URL parameters](https://duckduckgo.com/duckduckgo-help-pages/settings/params) · [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS)

## Installation

### Via URL Parameters

Append the following parameters to `https://duckduckgo.com/`:
`?k7=ffffff&kj=ffffff&k9=174ea6&k8=202124&kx=0d652d&kae=d2e3fc`

### Via Stylus / UserCSS

1. Install the [Stylus](https://github.com/openstyles/stylus) extension.
2. Create a new user style and paste `fmind.user.css`.
