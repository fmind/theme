# Fmind for DankMaterialShell

Light styling for DankMaterialShell, the Quickshell desktop shell for Wayland compositors such as niri and Hyprland.

## Installation

Save [fmind.json](fmind.json) anywhere, then open Settings → Theme & Colors, choose Custom and select the file. Alternatively set `"currentThemeName": "custom"` and `"customThemeFile"` to its absolute path in `~/.config/dms/settings.json`.
