# tig

Fmind theme for [tig](https://jonas.github.io/tig/).

Format: [tigrc(5)](https://github.com/jonas/tig/blob/master/doc/tigrc.5.adoc)

## Install

Source `fmind.tigrc` in your `~/.tigrc`:

```text
source path/to/tig/fmind.tigrc
```

tig only accepts ANSI color names and numbers, so it takes the Fmind colors from your terminal palette. Install the Fmind theme for your terminal first.
