# Nextcloud

Fmind theme for [Nextcloud](https://nextcloud.com/).

Format: [Nextcloud theme variables](https://github.com/nextcloud/server/blob/master/apps/theming/lib/Themes/DefaultTheme.php) · [Custom CSS app](https://github.com/nextcloud/theming_customcss)

## Install

1. In Nextcloud, install the **Custom CSS** app from the app store.
2. In Administration Settings -> `Theming` -> `Custom CSS`, paste the contents of `theme.css`.
3. In Personal Settings -> `Appearance and accessibility`, select **Light theme**; the stylesheet styles only that theme.
