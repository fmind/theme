# Fmind for FontForge

Light theme for [FontForge](https://fontforge.org/).

Format: [FontForge appearance resources](https://fontforge.org/docs/ui/misc/xres.html) · [bundled theme](https://github.com/fontforge/fontforge/blob/master/fontforgeexe/pixmaps/tango/resources.in)

## Installation

Save [fmind.txt](fmind.txt), for example as `~/.config/fontforge/fmind.txt`, set **File → Preferences → Generic → ResourceFile** to that path, and restart FontForge. FontForge no longer reads `~/.Xresources`. A ResourceFile replaces the default theme, so colors not listed in `fmind.txt` use the built-in defaults.
