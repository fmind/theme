# Fmind for MacDown

Preview CSS theme for MacDown.

Format: [MacDown 3000 bundled styles](https://github.com/schuyler/macdown3000/tree/main/MacDown/Resources/Styles) · [style loading in MPUtilities.m](https://github.com/schuyler/macdown3000/blob/main/MacDown/Code/Utility/MPUtilities.m)

## Installation

Copy [fmind.css](fmind.css) to `~/Library/Application Support/MacDown 3000/Styles/` for [MacDown 3000](https://macdown.app/), the maintained continuation of MacDown, or to `~/Library/Application Support/MacDown/Styles/` for the original MacDown. Choose fmind in Preferences → Rendering → CSS.
