# Fmind for VHS

Files: [fmind.tape](fmind.tape).

Format: [VHS Set Theme](https://github.com/charmbracelet/vhs#set-theme) · [Source](https://github.com/charmbracelet/vhs#source)

## Installation

Copy `fmind.tape` next to your tape and load it before the first command:

```elixir
Set FontFamily "GoogleSansCode Nerd Font Mono"
Source fmind.tape
```

The tape sets the 16 ANSI colors, background, foreground, cursor and selection of the [Ghostty](../ghostty/) theme. `mise run screenshots` records this repository's previews with it. Tested with VHS 0.12.1.
