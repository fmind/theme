# Fmind Telegram

Light theme palette for Telegram Desktop using Google Sans typography and Fmind tones.

## Install

1. In Telegram Desktop, go to **Settings** → **Chat Settings**.
2. Click the three dots menu at the top-right and choose **Create new theme** or **Import theme**.
3. Select [colors.tdesktop-palette](colors.tdesktop-palette) (or zip with `tiled.png` as `fmind.tdesktop-theme`).
4. Click **Apply this theme** to activate.
