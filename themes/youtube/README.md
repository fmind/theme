# YouTube

Fmind light user style for YouTube.

Format: [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS) · [Catppuccin YouTube userstyle](https://github.com/catppuccin/userstyles/blob/main/styles/youtube/catppuccin.user.less)

## Installation

1. Install the [Stylus](https://github.com/openstyles/stylus) extension in your browser.
2. Create a new style in Stylus and paste `fmind.user.css`.
3. In YouTube, set **Appearance** to **Light theme** in the account menu; the style does not restyle dark mode.
4. Open YouTube.
