# DOOM Emacs

Fmind light theme for DOOM Emacs.

Format: [def-doom-theme](https://github.com/doomemacs/themes/blob/master/doom-themes.el) · [doom-one-light](https://github.com/doomemacs/themes/blob/master/themes/doom-one-light-theme.el)

## Install

Copy `doom-fmind-theme.el` to `~/.doom.d/themes/` (or `~/.config/doom/themes/`), then set your theme in `config.el`:

```elisp
(setq doom-theme 'doom-fmind)
```
