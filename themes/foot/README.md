# Fmind for foot

Files: [fmind.ini](fmind.ini).

## Installation

Merge fragments into existing settings.

For foot 1.28+, copy to `~/.config/foot/themes/fmind.ini`; add `include=~/.config/foot/themes/fmind.ini` before any section in `~/.config/foot/foot.ini`. The fragment selects the light palette.
