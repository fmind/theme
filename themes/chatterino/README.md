# Fmind for Chatterino

Light theme for [Chatterino](https://chatterino.com/).

Format: [Chatterino theme schema](https://github.com/Chatterino/chatterino2/blob/master/docs/ChatterinoTheme.schema.json) · [bundled Light theme](https://github.com/Chatterino/chatterino2/blob/master/resources/themes/Light.json)

## Installation

Copy [fmind.json](fmind.json) to the `Themes` folder of Chatterino's settings directory: `%APPDATA%\Chatterino2\Themes\` on Windows, `~/Library/Application Support/chatterino/Themes/` on macOS or `~/.local/share/chatterino/Themes/` on Linux. Restart Chatterino, then select **Custom: fmind** in the theme setting.
