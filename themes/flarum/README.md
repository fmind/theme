# Flarum

Fmind theme for [Flarum](https://flarum.org/).

Format: [Flarum themes](https://docs.flarum.org/themes/) · [core root.less](https://github.com/flarum/framework/blob/2.x/framework/core/less/common/root.less)

## Install

In the Flarum admin **Appearance** page, under **Custom Styles**, click **Edit Custom CSS** and paste `fmind.css`.
