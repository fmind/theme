# Fmind for Hermes Agent

Light CLI skin for Hermes Agent.

Format: [Hermes Agent skins](https://hermes-agent.nousresearch.com/docs/user-guide/features/skins)

## Installation

Copy [fmind.yaml](fmind.yaml) to `~/.hermes/skins/fmind.yaml`, then set `display: skin: fmind` in `~/.hermes/config.yaml` (or run `/skin fmind` for the current session).
