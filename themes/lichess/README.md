# Fmind for Lichess

Light stylesheet for [Lichess](https://lichess.org/).

Format: [Lichess _theme.light.scss](https://github.com/lichess-org/lila/blob/master/ui/lib/css/theme/_theme.light.scss)

## Installation

Apply [fmind.user.css](fmind.user.css) via Stylus extension for lichess.org. In Lichess, set the background to **Light**, or to **Device theme** with a light system appearance. The style overrides only the light background's colors.
