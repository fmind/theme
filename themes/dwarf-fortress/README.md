# Dwarf Fortress

Fmind theme for [Dwarf Fortress](http://www.bay12games.com/dwarves/).

Format: [colors.txt](https://dwarffortresswiki.org/index.php/Colors.txt) · [Color scheme](https://dwarffortresswiki.org/index.php/Color_scheme)

## Install

Copy [colors.txt](colors.txt) to `prefs/colors.txt` (version 52.02 or later; the `prefs` folder location depends on portable mode). On older versions, replace `data/init/colors.txt` in your Dwarf Fortress installation.
