# Fmind for Sniffnet

Light theme for [Sniffnet](https://sniffnet.net/).

Format: [Sniffnet custom themes](https://sniffnet.app/wiki/custom-themes/) · [palette.rs](https://github.com/GyulyVGC/sniffnet/blob/main/src/gui/styles/types/palette.rs)

## Installation

In Sniffnet Settings → Style, select [fmind.toml](fmind.toml) with the custom theme file selector at the bottom of the tab.
