# Fmind for GoAccess

Light colors for [GoAccess](https://goaccess.io/).

Format: [goaccess.conf color syntax](https://github.com/allinurl/goaccess/blob/master/config/goaccess.conf) · [color items](https://github.com/allinurl/goaccess/blob/master/src/color.c)

## Installation

Append the lines of [fmind.conf](fmind.conf) to `~/.goaccessrc`; GoAccess has no include directive.
