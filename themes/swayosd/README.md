# Fmind for SwayOSD

Files: [fmind.css](fmind.css).

Format: [SwayOSD default style](https://github.com/ErikReider/SwayOSD/blob/main/data/style/style.scss) · [SwayOSD README](https://github.com/ErikReider/SwayOSD/blob/main/README.md)

## Installation

Copy to `~/.config/swayosd/style.css`, then restart your SwayOSD server through your existing session setup. Includes continuous and segmented indicators, labels and disabled states.
