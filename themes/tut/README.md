# Fmind for Tut

Light theme for [Tut](https://github.com/RasmusLindroth/tut).

Format: [tut snow-white.toml](https://github.com/RasmusLindroth/tut/blob/master/config/themes/snow-white.toml) · [tut theme option](https://github.com/RasmusLindroth/tut/blob/master/config/default_config.go)

## Installation

Place [fmind.toml](fmind.toml) in `~/.config/tut/themes/` and set `theme="fmind"` in the `[style]` section of `~/.config/tut/config.toml`.
