# Wox

Fmind light theme for the [Wox](https://github.com/Wox-launcher/Wox) launcher 2.4.5 or later (theme schema 2).

Format: [theme schema v2](https://github.com/Wox-launcher/Wox/blob/master/wox.core/common/theme_schema_v2.go) · [user theme loader](https://github.com/Wox-launcher/Wox/blob/master/wox.core/ui/manager.go)

## Installation

1. Copy [fmind.json](fmind.json) to Wox's user theme directory, `~/.wox/wox-user/themes/` by default (`%USERPROFILE%\.wox\wox-user\themes\` on Windows). Wox loads new theme files without a restart.
2. Open Wox settings, go to **Themes** → **Installed Themes**, select **Fmind** and click **Apply**.
