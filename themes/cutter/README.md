# Fmind for Cutter

Light color scheme for [Cutter](https://cutter.re/).

Format: [Cutter ColorThemeWorker](https://github.com/rizinorg/cutter/blob/dev/src/common/ColorThemeWorker.cpp) · [Rizin palette keys](https://github.com/rizinorg/rizin/blob/dev/librz/cons/pal.c)

## Installation

In Cutter, open Edit → Preferences → Appearance, choose Import next to Color Theme, select [fmind](fmind) and pick fmind. The file uses Rizin `ec` lines plus Cutter `#~` lines, so it cannot contain comments.
