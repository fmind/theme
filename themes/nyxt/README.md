# Nyxt

Fmind theme for [Nyxt Browser](https://nyxt.atlas.engineer/).

Format: [Nyxt theme library](https://github.com/atlas-engineer/nyxt/blob/master/libraries/theme/README.org) · [theme.lisp](https://github.com/atlas-engineer/nyxt/blob/master/libraries/theme/theme.lisp)

## Install

Requires Nyxt 3.9 or later, including 4.x: earlier versions reject the `:action-color` setting.

Load `fmind.lisp` in your `~/.config/nyxt/config.lisp`.
