# Fmind for Taskwarrior

Light color scheme for [Taskwarrior](https://taskwarrior.org/).

Format: [taskrc(5)](https://github.com/GothenburgBitFactory/taskwarrior/blob/develop/doc/man/taskrc.5.in) · [bundled light-16.theme](https://github.com/GothenburgBitFactory/taskwarrior/blob/develop/doc/rc/light-16.theme)

## Installation

Include [fmind.theme](fmind.theme) in your `~/.taskrc`:

```ini
include /path/to/taskwarrior/fmind.theme
```
