# Quiver

Fmind theme for [Quiver](https://www.yliansoft.com/quiver).

Format: [Quiver 3.3 bundled Themes/Light.json](https://www.yliansoft.com/static/downloads/QuiverFreeTrial.zip)

## Install

1. In Quiver Preferences, click **Load Theme...** beside the theme settings and choose `Fmind.json`.
2. Select **Fmind** as your UI theme.
