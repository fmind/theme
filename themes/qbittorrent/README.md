# Fmind qBittorrent

A high-contrast light theme for qBittorrent desktop and WebUI.

## Install

1. Compile the theme source into a `.qbtheme` bundle:
   ```sh
   rcc -binary -o fmind.qbtheme resources.qrc
   ```
2. Open qBittorrent and navigate to **Tools** → **Preferences** → **Behavior**.
3. Under **Interface**, check **Use custom UI Theme**.
4. Select the compiled `fmind.qbtheme` file and click **Apply**.
5. Restart qBittorrent to complete the setup.
