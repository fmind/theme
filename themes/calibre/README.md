# Calibre

Fmind palette for [Calibre](https://calibre-ebook.com/).

Format: [calibre palette import](https://github.com/kovidgoyal/calibre/blob/master/src/calibre/gui2/dialogs/palette.py)

## Install

In Calibre, open **Preferences** > **Look & feel** > **Main interface**, click **Adjust colors**, choose **Import**, select `fmind.calibre-palette` and click **OK**. Set **Color palette** to **Light**. The button needs the calibre interface style, and the import also resets custom dark-mode colors to calibre's defaults.
