# Renoise

Fmind theme for [Renoise](https://www.renoise.com/).

Format: [Renoise 3.5.4 bundled Themes/*.xrnc](https://files.renoise.com/demo/Renoise_3_5_4_Demo_Linux_x86_64.tar.gz) · [Renoise theme preferences](https://tutorials.renoise.com/wiki/Preferences)

## Install

In Renoise, open Preferences → Themes, import `fmind.xrnc`, then double-click Fmind in the theme list.
