# Fmind for Sandpack

Light theme for CodeSandbox [Sandpack](https://sandpack.codesandbox.io/).

Format: [SandpackTheme type](https://github.com/codesandbox/sandpack/blob/main/sandpack-react/src/types.ts) · [Sandpack themes](https://sandpack.codesandbox.io/docs/getting-started/themes)

## Installation

Import [fmind.json](fmind.json) into your Sandpack theme configuration.
