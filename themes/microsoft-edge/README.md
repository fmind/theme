# Microsoft Edge

Fmind light theme extension for Microsoft Edge.

Format: [Chrome theme manifest](https://developer.chrome.com/docs/extensions/develop/ui/themes) · [Chromium color keys](https://chromium.googlesource.com/chromium/src/+/refs/heads/main/chrome/browser/themes/browser_theme_pack.cc)

## Installation

1. Open Microsoft Edge and navigate to `edge://extensions`.
2. Enable **Developer mode** toggle.
3. Click **Load unpacked** and select the `microsoft-edge/` directory.
