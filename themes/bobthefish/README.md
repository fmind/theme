# bobthefish

Fmind color scheme for [bobthefish](https://github.com/oh-my-fish/theme-bobthefish).

Format: [bobthefish colors](https://github.com/oh-my-fish/theme-bobthefish/blob/master/functions/__bobthefish_colors.fish)

## Install

Source [fmind.fish](fmind.fish) in your `~/.config/fish/config.fish`. It defines the `bobthefish_colors` function, which bobthefish runs after its built-in scheme on every prompt. It sets every segment to a pale fill with dark text, so `theme_color_scheme` does not matter.
