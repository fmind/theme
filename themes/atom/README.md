# Fmind for Atom

Files: [package](package.json), [styles](styles/base.less).

## Installation

Configuration destinations are relative to `~/.config` unless an absolute path or another location is specified. Merge fragments into existing settings.

Copy the this directory directory to `~/.atom/packages/fmind-syntax/`; reload Atom, then Settings → Themes → Syntax Theme → Fmind. Use a light UI theme. Targets Atom 1.13–1.60; Atom is archived upstream.
