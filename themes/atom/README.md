# Fmind for Atom

Files: [package](package.json), [styles](styles/base.less).

## Installation

Merge fragments into existing settings.

Copy this directory to `~/.atom/packages/fmind-syntax/`; reload Atom, then Settings → Themes → Syntax Theme → Fmind. Use a light UI theme. Targets Atom 1.13–1.60; Atom is archived upstream.
