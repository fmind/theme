# LibreOffice

Fmind color palette for LibreOffice (Writer, Calc, Impress, Draw).

Format: [LibreOffice PaletteManager.cxx](https://github.com/LibreOffice/core/blob/master/svx/source/tbxctrls/PaletteManager.cxx) · [bundled libreoffice.soc](https://github.com/LibreOffice/core/blob/master/extras/source/palettes/libreoffice.soc)

## Installation

1. Copy `fmind.soc` to your LibreOffice user configuration directory:
   - Linux: `~/.config/libreoffice/4/user/config/`
   - macOS: `~/Library/Application Support/LibreOffice/4/user/config/`
   - Windows: `%APPDATA%\LibreOffice\4\user\config\`
2. Restart LibreOffice.
3. In any color picker dropdown, select the **fmind** palette; LibreOffice names a palette after its file.
