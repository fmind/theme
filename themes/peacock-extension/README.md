# Fmind for Peacock

Light theme favorite colors for VS Code [Peacock extension](https://marketplace.visualstudio.com/items?itemName=johnpapa.vscode-peacock).

Format: [Peacock `peacock.favoriteColors` setting](https://github.com/johnpapa/vscode-peacock/blob/main/package.json)

## Installation

Merge the favorite colors from [fmind.json](fmind.json) into your VS Code `settings.json`.
