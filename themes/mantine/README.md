# Mantine

Fmind theme preset for [Mantine](https://mantine.dev/).

Format: [Mantine colors](https://mantine.dev/theming/colors/) · [theme.types.ts](https://github.com/mantinedev/mantine/blob/master/packages/@mantine/core/src/core/MantineProvider/theme.types.ts)

## Install

Import `fmind.json` into your MantineProvider theme object.
