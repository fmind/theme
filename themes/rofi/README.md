# Fmind for Rofi

Files: [fmind.rasi](fmind.rasi).

Format: [rofi-theme(5)](https://davatorium.github.io/rofi/current/rofi-theme.5/) · [rofi default_theme.rasi](https://github.com/davatorium/rofi/blob/next/doc/default_theme.rasi)

## Installation

Copy to `~/.config/rofi/fmind.rasi`; use `rofi -show drun -theme ~/.config/rofi/fmind.rasi`. Colors inherit the standard layout.
