# Adminer

Fmind theme for [Adminer](https://www.adminer.org/).

Format: [Adminer css()](https://github.com/vrana/adminer/blob/main/adminer/include/adminer.inc.php) · [Adminer default.css](https://github.com/vrana/adminer/blob/main/adminer/static/default.css)

## Install

1. Copy `adminer.css` into the same directory as your `adminer.php` script.
2. Adminer will automatically load `adminer.css`.
