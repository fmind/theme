# Fmind for Dev-C++

Files: [Fmind.syntax](Fmind.syntax).

## Installation

Configuration destinations are relative to `~/.config` unless an absolute path or another location is specified. Merge fragments into existing settings.

Copy to your Dev-C++ configuration directory (normally `%APPDATA%\Dev-Cpp`, or the portable configuration directory). Restart, then Tools → Editor Options → Colors → Fmind. Uses native Windows BGR colors for C/C++, gutter, selection, breakpoints and error lines.
