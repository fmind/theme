# Fmind for Dev-C++

Files: [Fmind.syntax](Fmind.syntax).

Format: [Dev-C++ EditorOptFrm.pas](https://github.com/Embarcadero/Dev-Cpp/blob/master/Source/EditorOptFrm.pas)

## Installation

Copy to your Dev-C++ configuration directory (normally `%APPDATA%\Embarcadero\Dev-Cpp`, or `config\` beside `devcpp.exe` in portable mode). Restart, then Tools → Editor Options → Colors → Fmind. Uses native Windows BGR colors for C/C++, gutter, selection, breakpoints and error lines.
