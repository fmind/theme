# LimeChat

Fmind theme for [LimeChat](http://limechat.net/mac/).

Format: [LimeChat Sample.css](https://github.com/psychs/limechat/blob/master/Resources/Themes/Sample.css) · [Sample.yaml](https://github.com/psychs/limechat/blob/master/Resources/Themes/Sample.yaml)

## Install

Copy `Fmind.css` and `Fmind.yaml` to LimeChat's user theme folder: open **Preferences → Theme** and click **Open in Finder**. For the downloaded app this is `~/Library/Application Support/LimeChat/Themes/`; the sandboxed App Store app uses a folder inside its container. Then select **Fmind** under **Preferences → Theme**.
