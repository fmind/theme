# Fmind for Kristall

Light theme for [Kristall](https://kristall.random-projects.net/).

Format: [Kristall documentstyle.cpp](https://github.com/ikskuh/kristall/blob/master/src/documentstyle.cpp) · [settingsdialog.cpp import](https://github.com/ikskuh/kristall/blob/master/src/dialogs/settingsdialog.cpp)

## Installation

In Kristall's settings, open the **Style** tab, click **Import** and select [fmind.kthm](fmind.kthm). Select the **Fmind** preset, click **Load**, then confirm the settings dialog. The preset sets colors only; fonts use Kristall's defaults until you change them on the same tab.
