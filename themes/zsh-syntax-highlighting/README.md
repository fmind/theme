# Fmind for zsh-syntax-highlighting

Files: [fmind.zsh](fmind.zsh).

Format: [main highlighter styles](https://github.com/zsh-users/zsh-syntax-highlighting/blob/master/docs/highlighters/main.md) · [Zsh character highlighting](https://zsh.sourceforge.io/Doc/Release/Zsh-Line-Editor.html#Character-Highlighting)

## Installation

Source after the plugin in `.zshrc`. Use a truecolor terminal and the matching terminal palette. Does not replace your prompt.
