# Fmind for Kagi

Custom CSS userstyle for [Kagi search](https://kagi.com).

Format: [Kagi Custom CSS](https://help.kagi.com/kagi/features/custom-css.html)

## Installation

1. In Kagi's [Appearance settings](https://kagi.com/settings/appearance), set **Theme** to Light. The style overrides that theme's color variables.
2. Open [Custom CSS settings](https://kagi.com/settings/custom_css), turn on **Enable Custom CSS**, paste [fmind.css](fmind.css) and click **Apply Custom CSS**. Kagi does not apply custom CSS to its settings pages.
