# Fmind for Advent of Code

Light userstyle for [Advent of Code](https://adventofcode.com).

Format: [Advent of Code stylesheet](https://adventofcode.com/static/style.css) · [Stylus UserCSS](https://github.com/openstyles/stylus/wiki/Writing-UserCSS)

## Installation

Apply [fmind.css](fmind.css) via Stylus for `adventofcode.com`.
