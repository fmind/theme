# Fmind for MobaXterm

Files: [fmind.ini](fmind.ini).

Format: [MobaXterm configuration](https://mobaxterm.mobatek.net/documentation.html) · [Dracula MobaXterm colors](https://github.com/dracula/mobaxterm/blob/master/MobaXterm.ini)

## Installation

Close MobaXterm; merge `[Colors]` into `MobaXterm.ini` (its location is shown in Settings → Configuration → General). Reopen. Per-session color settings can override global colors.
