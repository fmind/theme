# LiteIDE

Fmind theme for [LiteIDE](https://github.com/visualfc/liteide).

Format: [LiteIDE colorhelp.md](https://github.com/visualfc/liteide/blob/master/liteidex/deploy/liteeditor/color/colorhelp.md)

## Install

1. Copy `fmind.xml` to `share/liteide/liteeditor/color/` within your LiteIDE directory, or to `LiteIDE.app/Contents/Resources/liteeditor/color/` on macOS.
2. Select `fmind.xml` under **Editor Color Scheme** in **View** > **Options** > **LiteEditor** > **Font & Colors**.
