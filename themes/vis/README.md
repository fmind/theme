# Fmind for vis

Light theme for [vis](https://github.com/martanne/vis).

Format: [vis solarized.lua](https://github.com/martanne/vis/blob/master/lua/themes/solarized.lua)

## Installation

Copy [fmind.lua](fmind.lua) to `~/.config/vis/themes/fmind.lua` and add `vis:command('set theme fmind')` to the `vis.events.INIT` handler in your `visrc.lua`.
