# Fmind for SpeedCrunch

Color scheme for [SpeedCrunch](https://speedcrunch.org/).

Format: [SpeedCrunch theme JSON schema](https://github.com/heldercorreia/speedcrunch/blob/main/doc/src/userguide/theme_json_schema.rst) · [colorscheme.cpp](https://github.com/heldercorreia/speedcrunch/blob/main/src/core/colorscheme.cpp)

## Installation

SpeedCrunch 1.0 or later: import [fmind.json](fmind.json) with **Import...** in **Settings → Appearance → Theme...**, or place it in `~/.local/share/SpeedCrunch/color-schemes/` (Linux), `~/Library/Application Support/SpeedCrunch/color-schemes/` (macOS) or `%APPDATA%\SpeedCrunch\color-schemes\` (Windows), then select **Fmind**.
