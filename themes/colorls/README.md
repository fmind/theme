# colorls

Fmind light color theme for `colorls`.

Format: [colorls custom configurations](https://github.com/athityakumar/colorls#custom-configurations) · [light_colors.yaml](https://github.com/athityakumar/colorls/blob/main/lib/yaml/light_colors.yaml)

## Install

Copy [fmind.yaml](fmind.yaml) to `~/.config/colorls/light_colors.yaml` and run `colorls --light`.
