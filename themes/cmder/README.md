# Fmind Cmder

Format: [ConEmu colors](https://conemu.github.io/en/SettingsColors.html) · [Cmder launcher](https://github.com/cmderdev/cmder/blob/master/launcher/src/CmderLauncher.cpp)

Cmder uses ConEmu settings. Install the [ConEmu scheme](../conemu/README.md) from [conemu/fmind.xml](../conemu/fmind.xml) in Cmder's `vendor/conemu-maximus5/ConEmu.xml`.
