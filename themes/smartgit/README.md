# SmartGit

Fmind theme for [SmartGit](https://www.syntevo.com/smartgit/).

Format: [SmartGit theme customization](https://docs.smartgit.dev/Latest/Manual/GUI/AdvancedSettings/Theme-Customization)

## Install

In SmartGit, open **Preferences → User Interface**, choose the custom entry in **Theme**, select `fmind.theme` in the **Open Theme Configuration File** dialog, and restart SmartGit.
