# Mattermost

Fmind light theme for Mattermost.

Format: [Mattermost custom themes](https://docs.mattermost.com/end-user-guide/preferences/customize-your-theme.html) · [Theme type](https://github.com/mattermost/mattermost/blob/master/webapp/channels/src/packages/mattermost-redux/src/selectors/entities/preferences.ts)

## Install

In the Mattermost web or desktop app, go to Settings → Display → Theme → Custom Theme, paste the JSON object from `fmind.json` into **Copy and paste to share theme colors**, and select **Save**.
