# CodeRunner

Fmind theme for [CodeRunner](https://coderunnerapp.com/).

Format: [CodeRunner TextMate themes](https://coderunnerapp.com/blog/releasenotes/2.0) · [TextMate themes](https://macromates.com/manual/en/themes)

## Install

In CodeRunner, open Preferences > Appearance and import `Fmind.tmTheme`.
