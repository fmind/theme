# Joplin

Fmind theme for [Joplin](https://joplinapp.org/).

Format: [Joplin custom CSS](https://joplinapp.org/help/apps/custom_css) · [Joplin theme variables](https://github.com/laurent22/joplin/blob/dev/packages/lib/services/style/themeToCss.ts) · [Joplin light theme](https://github.com/laurent22/joplin/blob/dev/packages/lib/themes/light.ts)

## Install

1. In Joplin desktop, open Tools → Options → Appearance (Joplin → Settings on macOS) and set the theme to **Light**. The stylesheet overrides that theme's color variables and leaves the dark sidebar unchanged.
2. Copy `userchrome.css` into your Joplin profile directory (`~/.config/joplin-desktop/` by default; the General page of the options shows the exact path), then fully quit and restart Joplin.
