# Fmind Insomnia

A clean light theme for the Insomnia API client.

## Install

1. In Insomnia, go to **Application** → **Preferences** → **Plugins**.
2. Click **Reveal Plugins Folder**.
3. Create a directory named `insomnia-plugin-theme-fmind` and copy [package.json](package.json) and [index.js](index.js) into it.
4. Navigate to the **Themes** tab and select **Fmind**.
