# Fmind for Wiremix

Light theme for the [wiremix](https://github.com/tsowell/wiremix) PipeWire audio mixer.

Format: [wiremix.toml reference](https://github.com/tsowell/wiremix/blob/main/wiremix.toml) · [theme.rs](https://github.com/tsowell/wiremix/blob/main/src/config/theme.rs)

## Installation

Copy the `[themes.fmind]` table from [fmind.toml](fmind.toml) into `~/.config/wiremix/wiremix.toml` (`$XDG_CONFIG_HOME/wiremix/wiremix.toml` if set) and set `theme = "fmind"` there, or run `wiremix --config /path/to/fmind.toml`. Use a white terminal background, such as one of the Fmind terminal themes.
