# Fmind for Notesnook

Light theme for [Notesnook](https://notesnook.com/).

Format: [Notesnook theme schema v1](https://github.com/streetwriters/notesnook-themes/blob/main/schemas/v1.schema.json) · [theme validator](https://github.com/streetwriters/notesnook/blob/master/packages/theme/src/theme-engine/validator.ts)

## Installation

In Notesnook, open Settings → Appearance → Themes, choose **Load from file** and select [fmind.json](fmind.json), then choose **Set as default**. See [Install a theme from file](https://notesnook.com/help/custom-themes/install-a-theme-from-file).
