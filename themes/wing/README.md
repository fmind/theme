# Wing

Fmind theme for [Wing Python IDE](https://wingware.com/).

Format: [Wing custom themes](https://wingware.com/doc/custom/qt-styles) · [bundled Dracula palette](https://github.com/dracula/wing/blob/master/palettes/dracula.plt)

## Install

Copy [fmind.plt](fmind.plt) into the `palettes` folder of Wing's Settings Directory, creating it if needed: `~/.wingpro12/palettes/` for Wing Pro 12 on Linux and macOS, or `%APPDATA%\Wing Pro 12\palettes\` on Windows. Wing's About box shows the exact Settings Directory. Restart Wing, then select Fmind under Preferences → User Interface → Light Editor (Use Selected). The palette sets editor and interface colors only; it ships no `syntax/` files for per-language token colors.
