# Oh My Posh

Fmind light theme for Oh My Posh.

## Installation

1. Copy `fmind.omp.json` to `~/.poshthemes/fmind.omp.json` (or your preferred config directory).
2. In your shell configuration (e.g. `.bashrc`, `.zshrc`, or PowerShell `$PROFILE`), initialize Oh My Posh with `--config /path/to/fmind.omp.json`.
