# Fmind for Cursor

A light theme for Cursor AI code editor.

Format: [VS Code color theme](https://code.visualstudio.com/api/extension-guides/color-theme) · [Cursor extensions](https://cursor.com/docs/configuration/extensions)

## Installation

1. With Cursor running, copy the `cursor/` folder into your Cursor extensions directory. Like VS Code, Cursor registers a folder added there only while it runs:
   - Linux: `~/.cursor/extensions/fmind-cursor`
   - macOS: `~/.cursor/extensions/fmind-cursor`
   - Windows: `%USERPROFILE%\.cursor\extensions\fmind-cursor`
2. Reload the window (`Ctrl+Shift+P` / `Cmd+Shift+P` → `Developer: Reload Window`).
3. Open Color Themes (`Ctrl+K Ctrl+T` / `Cmd+K Cmd+T`) and select **Fmind**.
