# bemenu

Fmind theme for [bemenu](https://github.com/Cloudef/bemenu).

Format: [bemenu options](https://github.com/Cloudef/bemenu/blob/master/client/common/common.c) · [BEMENU_OPTS](https://github.com/Cloudef/bemenu#environment-variables)

## Install

Source `fmind.sh` in your shell configuration or prefix your bemenu call.
