# Fmind for FreshRSS

Light theme for [FreshRSS](https://freshrss.org/).

Format: [FreshRSS theme loader](https://github.com/FreshRSS/FreshRSS/blob/edge/app/Models/Themes.php) · [Origine metadata.json](https://github.com/FreshRSS/FreshRSS/blob/edge/p/themes/Origine/metadata.json)

## Installation

Copy [metadata.json](metadata.json) and [fmind.css](fmind.css) into `p/themes/fmind/` in your FreshRSS installation, then select Fmind in Settings → Display. FreshRSS lists a theme only when its folder has `metadata.json`; `_frss.css` loads from the base theme.
