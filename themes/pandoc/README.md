# Pandoc

Fmind theme for [Pandoc](https://pandoc.org/).

Format: [Pandoc manual: --syntax-highlighting](https://pandoc.org/MANUAL.html#option--syntax-highlighting) · [skylighting style JSON](https://github.com/jgm/skylighting/blob/master/skylighting-core/src/Skylighting/Types.hs)

## Install

Pass the [theme file](fmind.theme) to Pandoc 3.8 or later with `--syntax-highlighting path/to/pandoc/fmind.theme`. Older versions use `--highlight-style path/to/pandoc/fmind.theme`.
