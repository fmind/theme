# Fmind for Zed

Files: [fmind.json](fmind.json).

Format: [Zed themes](https://zed.dev/docs/themes) · [Zed theme keys](https://github.com/zed-industries/zed/blob/main/crates/settings_content/src/theme.rs)

## Installation

Copy to `~/.config/zed/themes/fmind.json`; choose `fmind` with `theme selector: toggle`.
