# TiddlyWiki

Fmind palette for [TiddlyWiki](https://tiddlywiki.com/).

Format: [Vanilla palette](https://github.com/TiddlyWiki/TiddlyWiki5/blob/master/core/palettes/Vanilla.tid) · [colour macro](https://github.com/TiddlyWiki/TiddlyWiki5/blob/master/core/wiki/macros/CSS.tid)

## Install

1. Drag and drop `Fmind.tid` into your TiddlyWiki in the browser.
2. Click **Import**.
3. In Control Panel -> Appearance -> Palette, select **Fmind**.
