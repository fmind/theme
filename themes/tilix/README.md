# Fmind for Tilix

Files: [fmind.json](fmind.json).

Format: [colorschemes.d](https://github.com/gnunn1/tilix/blob/master/source/gx/tilix/colorschemes.d) · [bundled schemes](https://github.com/gnunn1/tilix/tree/master/data/schemes)

## Installation

Copy to `~/.config/tilix/schemes/fmind.json`; restart Tilix and choose Fmind in the profile’s Color settings.
