# Fmind for Chrome

Files: [manifest.json](manifest.json).

Format: [Chrome themes](https://developer.chrome.com/docs/extensions/develop/ui/themes) · [browser_theme_pack.cc](https://github.com/chromium/chromium/blob/main/chrome/browser/themes/browser_theme_pack.cc)

## Installation

Open `chrome://extensions`, enable Developer mode, choose Load unpacked, and select this directory. Styles browser chrome and the new-tab page, not websites.

## Microsoft Edge

Edge loads the same theme manifest. Open `edge://extensions`, enable Developer mode, choose Load unpacked, and select this directory.

## Vivaldi

Vivaldi has its own themes ([Vivaldi Themes](https://help.vivaldi.com/desktop/appearance-customization/browser-themes/)). Its **Open Theme** expects a theme ZIP file, so create the theme in the editor:

1. Open **Settings** → **Themes** and click **New Theme** after the existing themes.
2. Name it `Fmind`.
3. Set the colors: **Background** `#FFFFFF`, **Foreground** `#202124`, **Highlight** `#D2E3FC` and **Accent** `#174EA6`.

The editor saves changes automatically.
