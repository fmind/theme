# Ulauncher

Fmind light theme for Ulauncher application launcher.

Format: [Ulauncher color themes](https://github.com/Ulauncher/Ulauncher/blob/5.16.2/docs/themes/themes.rst) · [Ulauncher light theme.css](https://github.com/Ulauncher/Ulauncher/blob/5.16.2/data/themes/light/theme.css)

## Install

Copy the `ulauncher` directory to `~/.config/ulauncher/user-themes/fmind` and select Fmind in Ulauncher Preferences → Theme.
