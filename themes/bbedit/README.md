# BBEdit

Fmind light color scheme for BBEdit.

Format: [BBEdit User Manual](https://s3.amazonaws.com/BBSW-download/BBEdit_16.0.3_User_Manual.pdf) · [Toothpaste, bundled with BBEdit](https://github.com/toothpaste-theme/toothpaste/blob/master/Toothpaste.bbColorScheme)

## Install

Copy `Fmind.bbColorScheme` to `~/Library/Application Support/BBEdit/Color Schemes/` and select Fmind in Settings → Text Colors.
