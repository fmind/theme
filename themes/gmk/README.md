# Fmind GMK

Keycap colorway specification inspired by the Fmind minimalist light theme.

## Specifications

- **Alphas**: `#ffffff` background with `#202124` charcoal legends.
- **Modifiers**: `#f1f3f4` line gray background with `#202124` legends.
- **Accents**: `#174ea6` blue background with `#ffffff` legends.
- **Novelties / Selections**: `#d2e3fc` selection pale blue with `#174ea6` legends; `#fad2cf` pale red with `#a50e0e` legends.

See [fmind.json](fmind.json) for the machine-readable color definitions.
