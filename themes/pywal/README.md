# Pywal

Fmind theme for [pywal16](https://github.com/eylles/pywal16), the maintained fork of the archived [pywal](https://github.com/dylanaraps/pywal). Both read this JSON format.

Format: [pywal theme loader](https://github.com/eylles/pywal16/blob/master/pywal/theme.py) · [bundled light theme](https://github.com/eylles/pywal16/blob/master/pywal/colorschemes/light/github.json)

## Install

Run `wal --theme path/to/pywal/fmind.json` to apply the Fmind color scheme.
