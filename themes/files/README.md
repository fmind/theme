# Files

Fmind light custom theme for Files App on Windows.

## Installation

1. Copy `fmind.json` into `%LOCALAPPDATA%\Packages\49328JerryAutoStudio.Files_*\LocalState\Themes\` (or your Files Custom Themes directory).
2. Open Files App, navigate to **Settings → Appearance → Custom Themes**, and select **Fmind**.
