# Fmind for i3

Files: [fmind.conf](fmind.conf).

Format: [i3 client colors](https://i3wm.org/docs/userguide.html#client_colors)

## Installation

Copy to `~/.config/i3/fmind.conf`; add `include ~/.config/i3/fmind.conf` to the i3 config, then reload. Styles window borders and titles; your bar configuration stays separate.
