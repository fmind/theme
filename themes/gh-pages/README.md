# GitHub Pages

Fmind light stylesheet for GitHub Pages sites that use the [Primer](https://github.com/pages-themes/primer) Jekyll theme, the GitHub Pages default.

Format: [Primer theme stylesheet customization](https://github.com/pages-themes/primer#stylesheet) · [GitHub Pages default theme](https://github.com/github/pages-gem/blob/master/lib/github-pages/configuration.rb)

## Installation

1. Copy the `assets/` directory to the root of your GitHub Pages site. It adds `assets/css/style.scss`, which imports Primer and applies the Fmind colors and fonts, as Primer's README describes for custom styles.
2. Keep your own `_config.yml`. If it selects a theme other than Primer, set `theme: jekyll-theme-primer` instead.
3. Push the changes to GitHub.
