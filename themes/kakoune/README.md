# Kakoune

Fmind theme for [Kakoune](https://kakoune.org/).

Format: [Kakoune faces](https://github.com/mawww/kakoune/blob/master/doc/pages/faces.asciidoc) · [Kakoune colorscheme path](https://github.com/mawww/kakoune/blob/master/share/kak/kakrc)

## Install

Copy `colors/fmind.kak` to `~/.config/kak/colors/` and add `colorscheme fmind` to your `kakrc`.
