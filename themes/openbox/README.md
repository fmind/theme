# Openbox

Fmind theme for [Openbox](http://openbox.org/).

Format: [Openbox themes](https://openbox.org/help/Themes) · [theme.c](https://github.com/danakj/openbox/blob/main/obrender/theme.c)

## Install

1. Copy `Fmind/` to `~/.themes/Fmind/`.
2. Select **Fmind** in `obconf` or edit `~/.config/openbox/rc.xml`.
