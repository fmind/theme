# Fmind for Telegram macOS

Light palette for Telegram macOS native client.

Format: [Telegram macOS importPalette](https://github.com/TelegramMessenger/telegram-macos/blob/master/packages/TelegramTheme/Sources/TelegramTheme/ParseAppearanceColors.swift)

## Installation

In Telegram for macOS, open **Settings → Appearance** and create a theme with **New Theme** (a cloud theme on your account). **Edit** it, choose **Update from File...**, select [fmind.palette](fmind.palette), and save. Colors the palette leaves out come from the built-in Day theme.
