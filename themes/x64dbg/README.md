# Fmind for x64dbg

Color scheme for [x64dbg](https://x64dbg.com/). [style.ini](style.ini) sets every color x64dbg defines, so no colors from a previous theme remain.

Format: [theme loader](https://github.com/x64dbg/x64dbg/blob/development/src/gui/Src/Gui/MainWindow.cpp) · [color keys](https://github.com/x64dbg/x64dbg/blob/development/src/gui/Src/Utils/Configuration.cpp) · [bundled Dark theme](https://github.com/x64dbg/x64dbg/tree/development/bin/themes/Dark)

## Installation

1. Create `release\themes\Fmind\` in your x64dbg folder (beside the bundled `Dark` theme) and copy [style.ini](style.ini) into it.
2. Restart x64dbg and choose **Options** → **Theme** → **Fmind**.
