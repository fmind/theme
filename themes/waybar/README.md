# Fmind for Waybar

Files: [fmind.css](fmind.css).

Format: [Waybar styling](https://github.com/Alexays/Waybar/wiki/Styling) · [waybar-styles(5)](https://github.com/Alexays/Waybar/blob/master/man/waybar-styles.5.scd.in)

## Installation

Copy to `~/.config/waybar/fmind.css`; import with `@import "fmind.css";` in `~/.config/waybar/style.css` before your layout rules.
