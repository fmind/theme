# GameMaker Studio

Fmind light theme for the Code Editor 2 of [GameMaker](https://gamemaker.io/), formerly GameMaker Studio 2. It colors the editor background, caret, selection, gutter and GML syntax scopes; pair it with the built-in light IDE skin.

Format: [GameMaker Code Editor 2 preferences](https://manual.gamemaker.io/monthly/en/Setting_Up_And_Version_Information/IDE_Preferences/Text_Editor_2_Preferences.htm) · [TextMate themes](https://macromates.com/manual/en/themes)

## Installation

1. Open **File → Preferences** (**GameMaker → Settings** on macOS), enable **Code Editor 2 (Beta)** and restart the IDE.
2. In **Code Editor 2 (Beta) → Theme**, click **New...**, choose **from File**, select [fmind.tmTheme](fmind.tmTheme) and apply.
3. Optionally, select the light skin under **General Settings → IDE Skin**.
