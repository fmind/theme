# Marp

Fmind light theme for Marp markdown slide decks.

Format: [Marpit theme CSS](https://marpit.marp.app/theme-css) · [Marp CLI themes](https://github.com/marp-team/marp-cli#theme)

## Installation

1. Register `fmind.css` with Marp CLI (`--theme-set /path/to/marp/fmind.css`) or the Marp for VS Code `markdown.marp.themes` setting, then select it in your deck:
   ```markdown
   ---
   marp: true
   theme: fmind
   ---
   ```
2. Or pass `--theme /path/to/marp/fmind.css` to Marp CLI.
