# Fmind Vivaldi

Clean, minimal light theme for Vivaldi browser.

## Install

Vivaldi's **Open Theme** expects a theme ZIP file, so create the theme in the editor:

1. In Vivaldi, open **Settings** → **Themes** and click **New Theme** after the existing themes.
2. Name it `Fmind`.
3. Set the colors: **Background** `#FFFFFF`, **Foreground** `#202124`, **Highlight** `#D2E3FC` and **Accent** `#174EA6`.

The editor saves changes automatically.
