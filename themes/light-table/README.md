# Light Table

Fmind light theme for Light Table.

## Install

Copy `fmind.css` into your Light Table user directory, then add `[:app :lt.objs.style/provide-theme "fmind" "/path/to/fmind.css"]` and `[:editor :lt.objs.style/set-theme "fmind"]` to `user.behaviors`. `set-theme` selects the editor theme; `set-skin` only switches the UI skin.
