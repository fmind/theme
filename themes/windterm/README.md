# Fmind for WindTerm

Files: [UI](gui.theme), [icons](icon.theme), [syntax and terminal](scheme.theme).

## Installation

Configuration destinations are relative to `~/.config` unless an absolute path or another location is specified. Merge fragments into existing settings.

In your portable WindTerm directory, create `global/themes/fmind/` and copy the three `.theme` files there. Restart; open the command palette (`Alt+;`), find the theme command, and select fmind. Targets 2.7.0; references its bundled default and dige-white icons. Keep those bundled themes.
