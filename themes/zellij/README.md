# Fmind for Zellij

Files: [fmind.kdl](fmind.kdl).

Format: [Zellij themes](https://zellij.dev/documentation/themes) · [Zellij theme parser](https://github.com/zellij-org/zellij/blob/main/zellij-utils/src/kdl/mod.rs)

## Installation

Copy to `~/.config/zellij/themes/fmind.kdl`; set `theme "fmind"`. Uses named styles (0.42+).
