# Fmind for Yazi

Files: [fmind.toml](fmind.toml).

Format: [Yazi theme.toml](https://yazi-rs.github.io/docs/configuration/theme) · [Yazi theme-light.toml preset](https://github.com/sxyazi/yazi/blob/main/yazi-config/preset/theme-light.toml)

## Installation

Merge into `~/.config/yazi/theme.toml`; install the bat theme at the configured `mgr.syntect_theme` path.
