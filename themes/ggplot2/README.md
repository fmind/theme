# Fmind for ggplot2

Light theme for R ggplot2 visualizations.

Format: [ggplot2 theme()](https://ggplot2.tidyverse.org/reference/theme.html) · [complete themes](https://ggplot2.tidyverse.org/reference/ggtheme.html)

## Installation

Source [fmind.R](fmind.R) in your R session and add `+ theme_fmind()` to your plots.
