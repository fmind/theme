# Fmind for Streamlit

Files: [fmind.toml](fmind.toml).

Format: [Streamlit theming](https://docs.streamlit.io/develop/concepts/configuration/theming) · [Streamlit theme options](https://github.com/streamlit/streamlit/blob/develop/lib/streamlit/config.py)

## Installation

Merge `[theme]` into your project’s `.streamlit/config.toml`. Uses current Streamlit theming, including chart colors.
