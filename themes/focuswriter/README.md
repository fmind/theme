# Fmind for FocusWriter

Light theme for [FocusWriter](https://gottcode.org/focuswriter/).

Format: [bundled theme](https://github.com/gottcode/focuswriter/blob/main/resources/themes/gentleblues.theme) · [theme.cpp](https://github.com/gottcode/focuswriter/blob/main/src/theme.cpp)

## Installation

In FocusWriter Settings → Themes → Custom, choose Import and select [fmind.theme](fmind.theme).
