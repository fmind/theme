# Fmind for LazyGit

Files: [fmind.yml](fmind.yml).

Format: [lazygit Config.md color attributes](https://github.com/jesseduffield/lazygit/blob/master/docs/Config.md#color-attributes)

## Installation

Merge `gui.colorScheme` and `gui.theme` into `config.yml` in `lazygit --print-config-dir` (`~/.config/lazygit/config.yml` on Linux, `~/Library/Application Support/lazygit/config.yml` on macOS).
