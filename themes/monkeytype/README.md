# Fmind for Monkeytype

A light theme for [Monkeytype](https://monkeytype.com).

Format: [Monkeytype custom theme settings](https://github.com/monkeytypegame/monkeytype/blob/master/frontend/src/ts/components/pages/settings/custom-setting/Theme.tsx) · [custom theme colors schema](https://github.com/monkeytypegame/monkeytype/blob/master/packages/schemas/src/configs.ts)

## Installation

1. Open [Monkeytype](https://monkeytype.com) settings (`Settings` tab).
2. Under **theme**, select **custom**.
3. Set all ten colors, in the order Monkeytype lists them:
   - **Background**: `#ffffff`
   - **Main**: `#174ea6`
   - **Sub**: `#595d62`
   - **Text**: `#202124`
   - **Caret**: `#4285f4`
   - **Sub alt**: `#f1f3f4`
   - **Error**: `#a50e0e`
   - **Extra error**: `#a50e0e`
   - **Error** (colorful mode): `#a50e0e`
   - **Extra error** (colorful mode): `#a50e0e`
4. Click **save**, or **save as new** when signed in.
