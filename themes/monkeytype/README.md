# Fmind for Monkeytype

A light theme for [Monkeytype](https://monkeytype.com).

## Installation

1. Open [Monkeytype](https://monkeytype.com) settings (`Settings` tab).
2. Navigate to **Custom Theme**.
3. Apply the following color values:
   - **Background**: `#ffffff`
   - **Main**: `#174ea6`
   - **Sub**: `#9aa0a6`
   - **Text**: `#202124`
   - **Caret**: `#4285f4`
4. Alternatively, import the JSON settings from [fmind.json](fmind.json).
