# Uptime Kuma

Fmind theme for [Uptime Kuma](https://github.com/louislam/uptime-kuma) status pages.

Format: [Uptime Kuma StatusPage.vue](https://github.com/louislam/uptime-kuma/blob/master/src/pages/StatusPage.vue)

## Install

Uptime Kuma takes custom CSS per status page, not for the dashboard. Open a status page, click **Edit Status Page**, paste [theme.css](theme.css) into **Custom CSS**, and save.
