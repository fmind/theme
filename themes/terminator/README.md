# Fmind for Terminator

Files: [fmind.conf](fmind.conf).

Format: [terminator_config(5)](https://github.com/gnome-terminator/terminator/blob/master/doc/terminator_config.adoc)

## Installation

Merge the `[[fmind]]` profile under `[profiles]` in `~/.config/terminator/config`; select that profile in Preferences.
