# Fmind for Replugged

Light Discord client theme for [Replugged](https://replugged.dev/).

Format: [Replugged theme manifest](https://github.com/replugged-org/replugged/blob/main/src/types/addon.ts) · [Replugged theme loader](https://github.com/replugged-org/replugged/blob/main/src/main/ipc/themes.ts)

## Installation

1. Create a `fmind` folder in the Replugged themes folder: `~/.config/replugged/themes/` on Linux, `~/Library/Application Support/replugged/themes/` on macOS or `%APPDATA%\replugged\themes\` on Windows. **Open Themes Folder** under User Settings → Replugged → Themes opens it.
2. Copy [manifest.json](manifest.json) and [fmind.css](fmind.css) into that `fmind` folder.
3. Click **Load Missing Themes** (or restart Discord), then enable **Fmind**.
4. In User Settings → Appearance, choose Discord's **Light** theme: Fmind recolors its light theme tokens.
