# MetaTrader 5

Fmind light color scheme template for MetaTrader 5 charts.

Format: [MetaTrader 5 templates](https://www.metatrader5.com/en/terminal/help/charts_advanced/templates_profiles) · [stock ADX.tpl keys](https://github.com/softwaredevelop/metatrader/blob/main/MQL5/Profiles/Templates/ADX.tpl)

## Installation

1. Copy `Fmind.tpl` to the `MQL5\Profiles\Templates\` folder of your MT5 data folder (File → Open Data Folder, usually `%APPDATA%\MetaQuotes\Terminal\<ID>\MQL5\Profiles\Templates\`).
2. In MetaTrader 5, right-click any chart, choose **Templates**, and select **Fmind**.
