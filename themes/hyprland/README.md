# Fmind for Hyprland

Files: [fmind.lua](fmind.lua), [Hyprlock](hyprlock.conf).

Format: [Hyprland config options](https://wiki.hypr.land/configuring/core/config-options/) · [example hyprland.lua](https://github.com/hyprwm/Hyprland/blob/main/example/hyprland.lua) · [Hyprlock](https://wiki.hypr.land/hypr-ecosystem/user/hyprlock/)

## Installation

For Hyprland 0.55+, copy the Lua file beside `~/.config/hypr/hyprland.lua`; load `require("fmind")` after appearance settings. Includes borders, group titles and a white desktop background. For Hyprlock, merge the supplied background, input-field and clock widgets into `~/.config/hypr/hyprlock.conf`, replacing existing equivalents. Authentication settings remain yours.
