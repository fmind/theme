# Xournal++

Fmind light color palette for Xournal++.

Format: [GIMP palette parser](https://github.com/xournalpp/xournalpp/blob/master/src/core/gui/toolbarMenubar/model/ColorPalette.cpp) · [custom palette directory](https://github.com/xournalpp/xournalpp/blob/master/src/util/PathUtil.cpp)

## Install

Copy [fmind.gpl](fmind.gpl) (GIMP palette format) to `~/.config/xournalpp/palettes/`, restart Xournal++ and select Fmind in the palette settings under Preferences.
