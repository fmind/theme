# Fmind for LXTerminal

Files: [fmind.conf](fmind.conf).

Format: [LXTerminal setting.c](https://github.com/lxde/lxterminal/blob/master/src/setting.c)

## Installation

Close LXTerminal; merge the `[general]` entries into `~/.config/lxterminal/lxterminal.conf`, preserving your shortcuts and other settings. Reopen. Uses the Custom palette and disables brightening bold text.
