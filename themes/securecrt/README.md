# Fmind for SecureCRT

Color scheme for SecureCRT.

Format: [VanDyke color scheme import script](https://www.vandyke.com/support/scripting/scripting-examples/scripts/ImportAdditionalColorSchemesIntoGlobalConfig.py.txt) · [SecureCRT color configuration](https://www.vandyke.com/support/tips/colorconfig.html)

## Installation

Requires SecureCRT 8.7 or later.

1. Open the SecureCRT **Script** menu, choose **Run**, and select [fmind.py](fmind.py). The script adds the Fmind ANSI palette and color scheme to the global configuration and replaces earlier Fmind entries.
2. In **Session Options → Terminal → Appearance**, select **Fmind** from the **Current color scheme** list.
