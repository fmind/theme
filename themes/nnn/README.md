# Fmind for nnn

Light theme colors for [nnn](https://github.com/jarun/nnn).

## Installation

Source [fmind.sh](fmind.sh) or add the exports to your shell configuration:

```sh
export NNN_COLORS='4231'
export NNN_FCOLORS='030304020005060801030500'
```

Use a Fmind terminal palette with a white background. File colors use two-digit ANSI palette indexes, with `00` retaining the default foreground; they are not RGB hex values. nnn's file-type indicators and directory emphasis remain available alongside color.
