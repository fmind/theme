# Fmind for Heroic Games Launcher

Light theme for [Heroic Games Launcher](https://heroicgameslauncher.com).

Format: [custom theme loader](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher/blob/main/src/frontend/index.tsx) · [theme variables](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher/blob/main/src/frontend/themes.scss)

## Installation

1. Save [fmind.css](fmind.css) in a folder and keep its file name: Heroic derives the `fmind` body class from it.
2. In Heroic, open **Accessibility** in the sidebar and set **Custom Themes Path** to that folder.
3. Select **fmind.css** in **Select Theme**. After editing the file, select another theme and then **fmind.css** again to reload it.

Console Mode and the optional frameless window controls keep some dark-theme assumptions and are not tuned.
