# Fmind for Zathura

Files: [fmind.conf](fmind.conf).

Format: [zathurarc(5)](https://github.com/pwmt/zathura/blob/develop/doc/man/zathurarc.5.rst)

## Installation

Copy to `~/.config/zathura/fmind.conf`; add `include fmind.conf` to `~/.config/zathura/zathurarc`. UI colors only; document recoloring is opt-in.
