# Fmind for Xcode

Files: [fmind.xccolortheme](fmind.xccolortheme).

## Installation

Merge fragments into existing settings.

Copy to `~/Library/Developer/Xcode/UserData/FontAndColorThemes/`; restart Xcode, then Settings → Themes → Fmind. Install Google Sans and Google Sans Code for the specified fonts. Covers editor, console and documentation markup; use a light macOS appearance for the remaining UI.
