# Fmind for Raycast

A light theme for [Raycast](https://raycast.com).

Format: [ray.so Theme type](https://github.com/raycast/ray-so/blob/main/app/%28navigation%29/themes/lib/theme.ts) · [Raycast Themes](https://manual.raycast.com/themes)

## Installation

1. In Raycast, open Settings (`Cmd+,`).
2. Go to **General** → **Appearance** and open **Theme Studio** (Raycast Pro).
3. Create a light theme named Fmind with the colors in [fmind.json](fmind.json):
   - **Background**: `#ffffff`
   - **Secondary Background**: `#f1f3f4`
   - **Text**: `#202124`
   - **Selection**: `#d2e3fc`
   - **Loader**: `#174ea6`
