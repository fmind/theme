# Beyond Compare 4

Fmind color scheme for [Beyond Compare 4](https://www.scootersoftware.com/).

Format: [Import Settings](https://www.scootersoftware.com/v4help/dlgimport.html) · [Scooter Software color schemes](https://www.scootersoftware.com/kb/morecolors)

## Install

1. In Beyond Compare, open `Tools` -> `Import Settings...`.
2. Select `BCColors-Fmind.xml`, keep **Colors, Fonts** selected and finish the wizard.

Importing replaces earlier Folder View and File View color customizations. Beyond Compare 5 imports this Beyond Compare 4 scheme into its Light theme.
