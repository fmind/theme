# Homer

Fmind light theme for the [Homer](https://github.com/bastienwirtz/homer) dashboard.

Format: [Homer theming](https://github.com/bastienwirtz/homer/blob/main/docs/theming.md) · [Homer colors options](https://github.com/bastienwirtz/homer/blob/main/docs/configuration.md)

## Install

Merge the `defaults` and `colors` keys of [fmind.yml](fmind.yml) into Homer's `assets/config.yml`. Homer applies `colors.light` natively, and `colorTheme: light` keeps that palette active even when the system prefers dark mode; the dark-mode toggle still switches to Homer's dark colors.
