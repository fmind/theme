# Prompt

Fmind theme for [Prompt](https://panic.com/prompt/).

Format: [Prompt themes](https://help.panic.com/prompt/prompt-themes/)

## Install

Prompt for Mac imports iTerm2 color presets, so it uses the shared [iTerm2 preset](../iterm2/fmind.itermcolors). In Prompt, open **Settings** → **Themes**, click the gear icon, import [fmind.itermcolors](../iterm2/fmind.itermcolors), then select the imported theme. Prompt for iOS cannot import themes.
