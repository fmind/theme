# Qt5

Fmind light color scheme for Qt5 and Qt6 applications via `qt5ct` / `qt6ct`.

Format: [qt5ct loader](https://sourceforge.net/p/qt5ct/code/HEAD/tree/trunk/qt5ct/src/qt5ct-common/qt5ct.cpp) · [qt5ct airy.conf](https://sourceforge.net/p/qt5ct/code/HEAD/tree/trunk/qt5ct/colors/airy.conf) · [qt6ct loader](https://www.opencode.net/trialuser/qt6ct/-/blob/master/src/qt6ct-common/qt6ct.cpp)

## Install

Copy `fmind.conf` to `~/.config/qt5ct/colors/` (or `~/.config/qt6ct/colors/`), then select Fmind in `qt5ct` or `qt6ct` under Appearance → Color Scheme.
