# Unreal Engine

Fmind theme for [Unreal Engine](https://www.unrealengine.com/).

Format: [Unreal Engine EStyleColor](https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/SlateCore/EStyleColor)

## Install

1. In Unreal Engine 5, go to `Editor Preferences` -> `Appearance` -> `Themes`.
2. Click `Import` and select `Fmind.json`.
