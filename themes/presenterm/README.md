# Fmind for presenterm

Light presentation theme for [presenterm](https://github.com/mfontanini/presenterm).

Format: [presenterm theme definition](https://github.com/mfontanini/presenterm/blob/master/docs/src/features/themes/definition.md) · [bundled light theme](https://github.com/mfontanini/presenterm/blob/master/themes/light.yaml)

## Installation

Copy [fmind.yaml](fmind.yaml) to `~/.config/presenterm/themes/fmind.yaml` and select with `--theme fmind`.
