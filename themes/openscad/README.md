# Fmind for OpenSCAD

Color scheme for [OpenSCAD](https://openscad.org/).

Format: [bundled light-background.json](https://github.com/openscad/openscad/blob/master/color-schemes/editor/light-background.json) · [EditorColorMap.cc](https://github.com/openscad/openscad/blob/master/src/gui/EditorColorMap.cc)

## Installation

Copy [fmind.json](fmind.json) to `color-schemes/editor/` in your OpenSCAD user config directory (`~/.config/OpenSCAD/` on Linux), restart OpenSCAD, then select Fmind under Preferences → Editor.
