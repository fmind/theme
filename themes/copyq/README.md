# CopyQ

Fmind theme for [CopyQ](https://hluk.github.io/CopyQ/).

Format: [CopyQ themes](https://copyq.readthedocs.io/en/latest/theme.html) · [bundled themes](https://github.com/hluk/CopyQ/tree/master/shared/themes)

## Install

1. Open CopyQ **Preferences** > **Appearance**.
2. Click **Load Theme** and select `fmind.ini`.
