# Fmind for Qt Creator

Files: [editor](fmind.xml), [UI](fmind.creatortheme).

Format: [Qt Creator theme loader](https://github.com/qt-creator/qt-creator/blob/master/src/libs/utils/theme/theme.cpp) · [bundled UI themes](https://github.com/qt-creator/qt-creator/tree/master/share/qtcreator/themes) · [bundled editor styles](https://github.com/qt-creator/qt-creator/tree/master/share/qtcreator/styles)

## Installation

Copy the editor file into `styles/` and the UI file into `themes/` under your Qt Creator user resource directory. In Preferences, select Fmind under Environment → Interface and Text Editor → Font & Colors; restart. Targets Qt Creator 20.0.1. Locate your user resource directory using [Qt Creator’s settings documentation](https://doc.qt.io/qtcreator/creator-how-to-find-settings-files.html).
