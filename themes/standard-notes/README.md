# Standard Notes

Fmind theme extension for [Standard Notes](https://standardnotes.com/).

Format: [Standard Notes themes](https://standardnotes.com/help/plugins/themes) · [_colors.scss](https://github.com/standardnotes/app/blob/main/packages/styles/src/Styles/_colors.scss) · [publishing](https://standardnotes.com/help/plugins/publishing)

## Install

1. In Standard Notes, open **Preferences → Plugins**.
2. Under **Install Custom Plugin**, paste `https://cdn.jsdelivr.net/gh/fmind/theme@main/themes/standard-notes/ext.json` and click **Install**.
