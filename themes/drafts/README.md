# Fmind for Drafts

Light theme for [Drafts](https://getdrafts.com/).

Format: [Drafts theme format](https://docs.getdrafts.com/docs/extending/development/theme-format.html) · [default light theme](https://config.agiletortoise.com/examples/style-light.json)

## Installation

Custom themes need Drafts Pro. Download [fmind.draftsTheme](fmind.draftsTheme), open Editor Settings → Themes, choose Import and select the file, then pick Fmind as the light-mode theme.

The theme keeps the scopes of Drafts' default light theme and maps every editor and interface color to the Fmind palette. Markdown italics stay italic; quotations and change markup stay upright.
