# Powerlevel10k for Oh My Posh

Fmind theme for [Powerlevel10k on Oh My Posh](https://ohmyposh.dev/).

Format: [Oh My Posh configuration](https://ohmyposh.dev/docs/configuration/general) · [schema](https://github.com/JanDeDobbeleer/oh-my-posh/blob/main/themes/schema.json)

## Install

Reference `powerlevel10k_fmind.omp.json` in your Oh My Posh configuration:

```sh
oh-my-posh init pwsh --config path/to/powerlevel10k_fmind.omp.json | Invoke-Expression
```
