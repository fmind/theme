# Fmind CSS

CSS variables definition of the Fmind light color palette.

Format: [CSS custom properties](https://www.w3.org/TR/css-variables-1/) · [MDN guide](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_custom_properties)

## Installation

Import [fmind.css](fmind.css) into your web project or stylesheet:

```css
@import "fmind.css";
```
