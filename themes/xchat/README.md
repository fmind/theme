# XChat

Fmind light color theme for XChat and HexChat IRC clients.

## Install

With the client closed, merge the `color_0` to `color_15` lines from [colors.conf](colors.conf) into `~/.config/hexchat/colors.conf` (XChat: `~/.xchat2/colors.conf`), or copy the file there if none exists; the existing file also holds interface colors. Slots that share a hue keep text readable on white.
