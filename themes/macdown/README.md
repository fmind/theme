# MacDown

Fmind light editor theme for MacDown.

Format: [MacDown 3000 bundled themes](https://github.com/schuyler/macdown3000/tree/main/MacDown/Resources/Themes) · [PEG Markdown Highlight style parser](https://github.com/schuyler/macdown3000/blob/main/Dependency/peg-markdown-highlight/pmh_styleparser.c)

## Install

Copy `Fmind.style` to `~/Library/Application Support/MacDown 3000/Themes/` for [MacDown 3000](https://macdown.app/), the maintained continuation of MacDown, or to `~/Library/Application Support/MacDown/Themes/` for the original MacDown. Restart the app and select Fmind in Preferences → Editor → Theme.
