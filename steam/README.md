# Fmind Steam

A clean light theme for the Steam client interface using the Fmind color scheme.

## Install

1. Use a client patcher such as [Millennium](https://millennium.app/) to enable custom CSS styling.
2. Copy [webkit.css](webkit.css) into your Steam Millennium themes directory as `Fmind/webkit.css`.
3. Select **Fmind** in the theme picker and restart Steam.
