# Fmind for Cursor

A light theme for Cursor AI code editor.

## Installation

1. Copy the `cursor/` folder into your Cursor extensions directory:
   - Linux: `~/.cursor/extensions/fmind-cursor`
   - macOS: `~/.cursor/extensions/fmind-cursor`
   - Windows: `%USERPROFILE%\.cursor\extensions\fmind-cursor`
2. Restart Cursor or reload the window (`Ctrl+Shift+P` / `Cmd+Shift+P` → `Developer: Reload Window`).
3. Open Color Themes (`Ctrl+K Ctrl+T` / `Cmd+K Cmd+T`) and select **Fmind**.
