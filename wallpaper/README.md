# Fmind Wallpaper

Minimalist 4K vector wallpaper designed to complement the Fmind desktop experience.

## Install

1. Use [fmind.svg](fmind.svg) directly in desktop environments that support SVG desktop backgrounds (e.g. GNOME, KDE Plasma).
2. For platforms requiring raster images, render to PNG at your screen's native resolution:
   ```sh
   rsvg-convert -w 3840 -h 2160 fmind.svg -o fmind.png
   ```
3. Set `fmind.png` as your desktop wallpaper in your display settings.
