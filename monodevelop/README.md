# MonoDevelop

Fmind light color scheme for MonoDevelop and Xamarin Studio.

## Installation

1. Copy `Fmind.json` to your MonoDevelop styles directory:
   - Linux: `~/.config/MonoDevelop/styles/`
   - macOS: `~/Library/Preferences/MonoDevelop/styles/`
   - Windows: `%APPDATA%\MonoDevelop\styles\`
2. Open MonoDevelop, go to **Tools → Options → Text Editor → Syntax Highlighting**.
3. Select **Fmind**.
