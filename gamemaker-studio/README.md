# GameMaker Studio

Fmind light theme for GameMaker Studio 2.

## Installation

1. Copy `fmind.json` into your GameMaker Studio 2 user themes directory:
   - Windows: `%APPDATA%\GameMakerStudio2\Themes\`
   - macOS: `~/Library/Application Support/GameMakerStudio2/Themes/`
2. Open GameMaker Studio 2, go to **File → Preferences → General Settings → Theme**.
3. Select **Fmind**.
